## 1. 这是什么

SecureVault 是一个常驻托盘的桌面小工具，用来：

- **监控**：记录每一次 U 盘 / 硬盘的接入与移除（时间、盘符、总线、型号、VID:PID、
  序列号、容量、文件系统、物理磁盘号等等）；
- **自动复制**：插上盘就按规则把文件**增量复制**到你指定的目录，全程静默；
- **排除**：按设备属性（12 种）和文件名 / 扩展名把不想复制的对象排除掉；
- **定时切换**：按时间段自动在「复制模式 / 监控模式 / 关闭」之间切换，支持跨午夜；
- **安全**：主密码 + 恢复码，记录与设置用 AES-256-GCM 逐字段加密存在本机 SQLite 里。

技术栈：Python 3.8+、Tk（自绘 Win10 风格界面）、pywin32（托盘 / 设备事件）、
SQLite、Windows CNG 或 `cryptography`（AES-256-GCM）、DPAPI（可选的后台自动解锁）。

## 2. 快速开始

**打包版（推荐，免安装 Python）**

1. 把整个 `dist\SecureVault\` 文件夹复制到**任意一台 Windows 电脑的任意可写位置**
   （例如 `D:\SecureVault\`），双击里面的 `SecureVault.exe`。
   程序自带运行环境，**目标电脑不需要安装 Python 或任何依赖**。
2. 第一次会弹出一个**老式小弹窗「首次使用」**，要求设置**至少 8 位**的主密码
   （带「显示密码」勾选框）；两次确认后显示一个**只显示一次**的恢复码
   （格式 `XXXX-XXXX-XXXX`），请抄下来或另存为 txt。
3. 设好后主面板就打开了（默认直接进入上次停留的页面）：选模式、设复制目标目录，然后照常用。

> **便携性**：整个文件夹复制到任何一台 Windows 电脑的任何可写位置都能直接跑，
> 目标电脑**不需要安装 Python 或任何依赖**（实测：拷到别的目录 + PATH 里完全没有 Python 也能启动与自检）。

> **为什么交付的是文件夹版而不是单文件 exe？**
> 本机 PyInstaller 3.6 + Python 3.8 打出来的单文件 exe 在初始化 Tcl/Tk 时会稳定失败
> （`Can't find a usable init.tcl`）。已用内置的 `-diag` 逐层查过：解压目录里
> `tcl/init.tcl`、`tcl/encoding` 都在、内容也对，但 `Tcl_Init` 仍返回错误 ——
> 是 PyInstaller 3.6 引导程序与 Tcl 8.6 在单文件模式下的兼容问题，不是我们代码的问题。
> 文件夹版把 Tcl/Tk 数据放在程序目录里，**实测连续启动稳定**、启动更快，也完全不往
> C 盘写临时文件。整个文件夹一起复制即可；`SecureVault.exe` 必须和同目录的其它文件在一起，
> 分发时可以整个文件夹压成 zip。

**源码运行**

```powershell
# 需要本机已装 Python 3.8+（含 tkinter）与 pywin32
python main.py          # 带控制台，方便看错误
pythonw SecureVault.pyw # 不带控制台（也可双击「启动 SecureVault.bat」）
```

## 3. 功能一览

### 3.1 三种模式

| 模式 | 行为 |
|---|---|
| **复制模式** | 记录设备信息 + 把盘内文件（应用排除规则后）增量复制到目标目录 |
| **监控模式** | 只记录接入 / 移除与设备详情，不复制任何文件 |
| **关闭** | 不监控不复制，只在文本日志里留一行说明 |

手动模式在「状态」页切换并点「应用模式」；定时计划命中时以计划为准。

### 3.2 定时切换

- 任意多条 `HH:MM - HH:MM → 模式`，**支持跨午夜**（`22:00 - 06:00`）。
- 每条可单独选择生效的星期（默认每天）、可单独启用 / 停用。
- 计划每 20 秒重算一次；界面会显示「下次切换还有多久」。
- 时间写法宽松：`8:00` 会自动补成 `08:00`；格式或范围不对会当场提示。

### 3.3 复制

| 能力 | 说明 |
|---|---|
| 增量复制 | 按 **(文件大小, 修改时间)** 判断，只复制新文件与改动过的文件；索引**按设备隔离**——同一个盘符换了另一块盘不会被误判成"文件没变" |
| 文件夹命名 | 没有别名时 = **卷标 > 型号 > 盘符**；有别名时 = `<原名>_<别名>`，并做 Windows 文件名净化 |
| 改别名 | 会把已有的 `<原名>` 目录**改名**为 `<原名>_<别名>`（保留已复制的文件），之后继续往里面增量复制 |
| 全程静默 | 不调用 cmd / powershell / robocopy，不弹任何系统窗口 |
| 失败可恢复 | 单文件失败按次数重试（默认 2 次），仍失败只记一条并继续整批 |
| 空间保护 | 复制前算「待复制字节 vs 目标剩余空间」，不足则不开始；过程中每 200 个文件复查，不足则安全停止（已复制的保持有效） |
| 长路径 | 所有文件访问都加 `\\?\` 前缀，支持超过 260 字符的路径 |
| 并发保护 | 同一时刻只跑一个复制任务，多个盘同时接入不会互抢 |
| 启动补偿 | 程序启动时会对「已经插着的设备」补一次事件，避免漏掉 |

### 3.4 密码 / 恢复码 / 上锁

- 首次使用必须设置至少 8 位主密码，并会拿到一次性恢复码。
- **解锁与首次设置都是独立的老式小弹窗**（不是主窗口里的页面，也不占满屏幕），
  界面是经典原生样式（凹入输入框 + 凸起按钮），并带「显示密码」勾选框；
  解锁之前窗口标题与界面里都不显示软件名。
- 忘记密码：解锁界面点「忘记密码」，**先校验恢复码**（先查格式、再真的拿它去解一次密钥库），
  通过之后才会让你设置新密码；重置成功会**轮换出新恢复码**（旧码立即失效）。
- 连续 5 次密码错误 → **锁定 60 秒**，锁定状态写入磁盘，重启程序依然生效。
- **只有在开软件时输错密码才计数**；在设置里改密码 / 重新生成恢复码 / 确认退出 /
  危险操作确认时输错**不计数**，也不会因此被锁定。
- 改密码需要当前密码，恢复码保持不变；「重新生成恢复码」同样需要密码。
- **清除监控记录与清除日志前都要输入密码确认**（同样不计数）。
- **关闭面板 = 收进托盘 + 立即上锁**，再次打开必须重新输密码；
  默认设置下后台监控与复制**继续运行**（这是「插上盘就自动复制」能成立的前提）。
- 后台运行靠一份由 **Windows 用户凭据（DPAPI）**保护的密钥副本，
  只在本机本用户下能解开；不想要可以在设置里关掉（关掉后重启必须先手动解锁）。

### 3.5 托盘

- 托盘提示只有 `SecureVault` 一个名字。
- **左键单击 = 打开 / 解锁面板**；**右键菜单只有「退出」**。
- 同一时刻只会有一个面板窗口（重复点击不会叠窗）。
- Explorer 崩溃重启后会自动重新加回托盘图标；图标暂时加不上时会每秒重试。

### 3.6 监控记录

- 记录字段：时间、事件、处理结果、盘符、卷标、总线类型、型号、厂商、VID、PID、
  USB 序列号、磁盘序列号、文件系统、总容量、剩余容量、物理磁盘号、设备实例 ID、
  卷 GUID、设备路径、是否可移动、复制文件数 / 字节数 / 耗时、目标目录、备注。
- 查询：关键词 + 字段限定 + 事件类型 + 时间范围；每页 100 条，可翻页。
- **导出 CSV**（UTF-8 BOM，Excel 直接打开不乱码）。
- 清除记录：7 / 14 / 30 天前或全部（都要二次确认，程序**不会**自动删记录）。
- 双击看详情，右键可以「加入排除名单 / 复制序列号 / 复制整行」。

### 3.7 排除名单

设备规则支持 12 种属性（规则之间是「或」，命中任意一条就只记录、不复制）：
总线类型、USB 厂商 ID、USB 产品 ID、USB 序列号、磁盘序列号、设备型号、卷标、
文件系统、盘符、物理磁盘号、设备实例 ID、容量（`512MB`、`>=64GB`、`<=2GB`、`<2GB`…）。

文件名单支持三类：排除的文件 / 文件夹名（通配符 `*` `?`）、排除的扩展名、
只复制这些扩展名（留空表示全部）。

### 3.8 工具

- **工具 1 · 桌面整理**：把桌面（或指定目录）增量复制到目标目录下的 `桌面` 文件夹。
- **工具 2 · 设备别名**：给设备起别名，别名会覆盖界面显示名与复制出的文件夹名。
  支持按卷标 / 型号 / VID / PID / USB 序列号 / 磁盘序列号 / 设备实例 ID 匹配，
  也可以「用本机磁盘填充匹配值」一键取值。

### 3.9 日志

- 纯文本，**按天一个文件**：`SecureVaultData\logs\yyyy-mm-dd.txt`，UTF-8、CRLF。
- 行格式：`2026-09-18 19:04:23.123 [INFO ] 内容`。
- 默认自动删除 14 天前的日志，可在设置里改成 7 / 30 天。
- 日志页可以预览、打开日志文件夹、清除 7 天前或清除全部。

## 5. 数据与安全

所有数据只写在**程序所在目录**下的 `SecureVaultData\`：

| 路径 | 内容 |
|---|---|
| `vault.db` | 加密 SQLite（记录、排除规则、名单、别名、定时计划、设置、增量索引） |
| `vault.db-wal` / `vault.db-shm` | WAL 模式的临时文件（正常现象） |
| `keystore.json` | 密钥库：KDF 参数、两份被包裹的 DEK、校验值、失败计数与锁定时间 |
| `logs\yyyy-mm-dd.txt` | 按天的纯文本日志 |
| `tmp\` | 原子写用的临时文件 |
| `legacy-go\` | 如果检测到旧版（Go）数据库，会**原样搬到这里**，不删除 |

**绝不写 C 盘其它位置、不写注册表。**

### 密钥体系

```
密码   ─┐                                    ┌── pwdWrap (AES-256-GCM) ──┐
        ├─ PBKDF2-HMAC-SHA256(20 万次, 16B salt) ─→ KEK(32B)+KMAC(32B)  ├─→ 随机 DEK(32B)
恢复码 ─┘                                    └── recWrap (AES-256-GCM) ──┘
```

- KDF：PBKDF2-HMAC-SHA256，随机 16 字节 salt，**200000 次**，每次派生 64 字节
  （前 32 字节当 KEK，后 32 字节当校验密钥）。
- 包裹：AES-256-GCM，随机 12 字节 nonce，附加数据固定
  `SecureVault|keystore|v1|pwd` / `...|rec`；校验用 HMAC-SHA256，不存明文哈希。
- 恢复码比较忽略大小写与横线，用常量时间比较；明文恢复码绝不落盘。
- **磁盘格式与旧 Go 版完全一致**，所以升级后原来的密码与恢复码照旧可用
  （旧数据库会被搬到 `legacy-go\`，需要时可用旧版程序打开）。

### 数据库加密

敏感字段逐字段 AES-256-GCM 加密后以 BLOB 存储（布局 `nonce(12) || 密文 || tag(16)`，
附加数据固定 `SecureVault|field|v1`）；只有时间、事件、动作、容量等非敏感列是明文。
增量索引的源路径用 HMAC-SHA256 盲索引，路径本身不落明文。
自检里有一条硬断言：**直接在数据库文件里搜不到明文序列号与卷标**。

## 6. 命令行参数

参数写法宽松：`-silent`、`--silent`、`/silent` 都识别。

| 参数 | 说明 |
|---|---|
| `-silent` | 静默启动：只驻留托盘，不显示任何窗口（开机自启用的就是它） |
| `-debug` | 输出调试信息（默认全程静默） |
| `-help` | 显示帮助 |
| `-review` | 界面评审模式：跳过密码、写入演示数据后直接打开面板（**开发用**） |
| `-autotest` | 自动验收：跑完整流程并把结果写进 `autotest.log`（**开发用**） |
| `-selftest` | 只跑逻辑自检（**开发用**） |
| `-diag` | 打印 Tcl/Tk 与运行环境诊断信息（**开发用**，排查启动问题） |

开发参数使用独立数据目录 `SecureVaultData-dev\`，不会碰正式数据。

退出码：`0` 正常退出（含「检测到已有实例」）｜`3` 程序目录不可写｜`4` 启动失败。

## 10. 已知限制

1. **USB 真机分支未端到端验证**：本机只有 NVMe 固定盘，没有可插拔 U 盘。
   VID / PID / USB 序列号的解析与「沿设备树向上找 USB 节点」的逻辑已用伪造实例 ID 覆盖，
   但**建议你插一次真 U 盘复核**（插上后日志与「当前设备」列表会立即显示）。
2. 复制目标不建议放在源盘内部（把 U 盘内容复制回它自己），程序不会拦截这种配置。
3. 别名允许重名，重复时按数据库返回顺序取第一条。
4. 托盘图标依赖 Explorer：如果在没有桌面外壳的会话里运行（某些服务 / 计划任务环境），
   图标加不上属正常现象，程序仍会运行并每秒重试。
5. 交付的是**文件夹版**（`dist\SecureVault\`）：`SecureVault.exe` 必须和同目录的
   `_internal\` 等文件放在一起，不能只把 exe 单独拿走；分发时可以整个文件夹压成 zip。
   单文件 exe 在本机 PyInstaller 3.6 下会因 Tcl 初始化失败而无法启动（详见第 2 节说明）。
6. 「选择文件夹 / 另存为 CSV」用的是系统文件对话框（系统实现，非自绘）。
6. 开发参数 `-review` / `-autotest` / `-selftest` 使用 `SecureVaultData-dev\`，
   但**生产数据目录名仍是 `SecureVaultData\`**，两者互不影响。

## 11. 常见问题

**Q：双击没反应？**
先看托盘有没有图标（可能藏在「^」里）。如果程序目录不可写，会出现一个错误框并退出（退出码 3）。
也可以先用 `python main.py` 在控制台里跑一次看报错。

**Q：忘了密码怎么办？**
解锁界面点「忘记密码 / 用恢复码重置」。恢复码也丢了，就真的无法解密了（这是设计如此）。

**Q：关掉窗口后还在复制吗？**
默认还在。设置页「关闭面板后继续在后台监控与复制」关掉后就会停止引擎，重启后必须先解锁。

**Q：为什么启动时会记录 / 复制已经插着的盘？**
这是「启动补偿」：程序启动前就插好的设备也会被处理一次，否则会漏掉。增量复制会跳过没变化的文件。

**Q：数据能搬到别的机器吗？**
数据库本身可以搬，但**后台自动解锁的密钥副本是 DPAPI 保护的**，换机器 / 换账户就失效
（需要重新输密码，这是它安全边界的代价）。
