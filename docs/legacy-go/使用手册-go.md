## 1. 这是个什么软件

SecureVault 是一个 **U 盘 / 移动硬盘 自动复制与监控工具**：

- **监控模式**：记住谁插过这台电脑（时间、盘符、卷标、型号、VID/PID、序列号、容量……）。
- **复制模式**：插上设备后，把里面的文件**增量复制**到你指定的目录，文件夹名自动取设备名。
- 三种模式：**复制模式 / 监控模式 / 关闭**，可手动切换，也可用时间段自动切换。
- 全程**静默**：复制、扫描、出错都不会弹出系统窗口，也不会闪出 cmd / PowerShell 黑框。
- 数据**强加密**保存在自己身边（见下一节），密码 + 恢复码双保险。

## 2. 系统要求与放置位置

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / Windows 11，**64 位** |
| 权限 | 普通用户即可，不需要管理员，不会弹 UAC |
| 依赖 | 无。单个 exe，不需要 .NET / VC 运行库 / 安装程序 |
| 屏幕 | 支持 100% / 125% / 150% / 200% 缩放（Per-Monitor V2） |
| 磁盘 | 约 8 MB（exe）+ 数据目录（随记录与日志增长） |

**放哪里**：新建一个文件夹（例如 `D:\SecureVault\`），把 `SecureVault.exe` 放进去，双击即可。

> ⚠️ 不要放在**只读目录**（例如只读光盘、被策略保护的目录）。程序启动时会在 exe 同级创建并写入数据目录，写不进去就会直接退出（不会弹窗）。

> 💡 exe 可以放在 U 盘里带着走，数据目录会跟着 exe 走（见第 3 节）。但每换一台电脑都要重新设置密码。

## 3. 数据存在哪里

所有数据都写在 **exe 所在文件夹**下的 `SecureVaultData\`：

```
D:\SecureVault\
├─ SecureVault.exe
└─ SecureVaultData\            ← 全部数据都在这里
   ├─ keystore.json            ← 密钥库：KDF 参数、被包裹的主密钥、校验值、失败计数/锁定时间
   ├─ vault.db                 ← 加密数据库（记录、规则、名单、别名、计划、设置、增量索引）
   ├─ vault.db-wal / -shm      ← 运行时临时出现，程序退出后会被合并回收
   ├─ logs\
   │  └─ 2026-09-17.txt        ← 纯文本日志，一天一个文件
   └─ tmp\                     ← 写入时用的临时目录（原子写、可写性探测）
```

- 软件**不写注册表**，不往系统目录或用户目录里塞东西。
- **唯一的例外**是开机自启快捷方式：`C:\Users\<你的用户名>\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\SecureVault.lnk`。它由「设置 → 开机自动启动」创建，可以随时在软件里关掉，也可以直接删掉这个文件。
- 卸载 = 删除 exe 所在文件夹（含 `SecureVaultData`）+ 删掉上面那个快捷方式，没有残留。

## 4. 第一次使用

### 步骤 1：双击 `SecureVault.exe`

程序**不会**显示主界面，而是**直接缩到右下角托盘**（任务栏时钟旁边）。这是设计如此：开机自启时也一样，不打扰你。

### 步骤 2：打开面板

在托盘图标上**单击（或双击）**，弹出「SecureVault · 首次设置」窗口：

```
┌─ SecureVault · 首次设置 ────────────────────────────┐
│ 首次使用：请设置主密码                              │
│ 密码至少 8 位，用于加密本机的全部数据。             │
│                                                     │
│   主密码     [••••••••••            ]               │
│   确认密码   [••••••••••            ]               │
│   （出错时这里显示红色提示文字）                    │
│                                                     │
│                     [ 确定 ]  [ 取消 ]              │
└─────────────────────────────────────────────────────┘
```

- 两次输入必须一致，**至少 8 位**（按字符计，中文也算一个字符）。
- 密码太短 / 两次不一致时，窗口内会给出提示，不会关闭。
- 点「取消」或右上角 × 会再问一次「尚未设置密码，确定要取消并退出设置吗？」，确认后程序继续驻留托盘，可以稍后再从托盘打开。

### 步骤 3：立刻抄下恢复码（**只显示这一次**）

密码设置成功后，紧接着弹出：

```
┌─ SecureVault · 恢复码（只显示这一次） ──────────────────────┐
│ 请立即抄写并妥善保存下面的恢复码                            │
│ 忘记密码时，只能用这个恢复码重置密码。                      │
│ 它只显示这一次，程序不会保存明文，也无法帮你找回。          │
│ 如果密码和恢复码都丢了，数据将永久无法解密。                │
│                                                             │
│   [ 7K2M-9QXA-4B1Z                        ] （只读，可选中） │
│   复制结果提示…                                             │
│                                                             │
│   [ 复制恢复码 ] [ 另存为 txt ]      [ 我已保存，继续 ]      │
└─────────────────────────────────────────────────────────────┘
```

- 恢复码格式固定为 `XXXX-XXXX-XXXX`：大写字母 + 数字，共 12 位有效字符，中间两个横线。
- 三种保存方式，任选其一或都用：
  1. **手抄**到纸上（推荐，最不容易丢）；
  2. 点「**复制恢复码**」→ 粘贴到你自己的记事本 / 密码管理器；
  3. 点「**另存为 txt**」→ 存成一个文本文件（默认文件名 `SecureVault-恢复码.txt`，内容含生成时间）。
- 点「我已保存，继续」会再确认一次「确认已经保存好恢复码了吗？」；直接关窗口或按 Esc 也会先确认。
- 确认通过后，程序自己也不再有这个码：磁盘上只有它的派生值，**没有办法再显示第二次**。

### 步骤 4：设置复制目标目录

主面板打开后，切到「**设置**」页 →「U 盘复制目标根目录」→ 点「选择…」选一个目录（例如 `D:\USB备份`）→ 点「**保存设置**」。

> 如果目录不存在，会问你「目标目录当前不存在，要现在创建它吗？」。

> 界面是 Windows 10 风格：白色底、浅灰标签条、白色圆角卡片；窗口拉小之后页面可以**上下滚动**
> （鼠标滚轮、PageUp/PageDown、Home/End、↑/↓），右侧有细滚动条。

### 步骤 5：选择运行模式

切到「**状态**」页 → 勾选「**复制模式**（插入设备后自动增量复制）」或「**监控模式**（只记录，不复制）」→ 点「**应用模式**」。

底部状态栏会显示：`当前模式：复制模式 ｜ 复制目标：D:\USB备份 ｜ 待机`。

### 步骤 6：关掉面板也没关系（关键！）

**软件是常驻托盘的后台工具：面板关掉之后，监控与复制照样在跑。**

- 点窗口右上角 × 关闭 → 窗口收进托盘、**面板上锁**（要再看界面得重新输密码），
  **后台监控与复制继续运行**。
- 打开程序时（含开机自启）也会**自动在后台恢复监控与复制**，不需要输密码。
- 如果你希望"关掉面板就彻底停下来"，去「设置」页取消勾选
  「**关闭面板后继续在后台监控与复制**」并保存 —— 那样关闭面板就会停引擎、关数据库、清空内存密钥
  （代价是每次重启后都要先手动打开面板解锁才会开始监控）。

> 默认设置就是"一直盯着"：插上 U 盘就会记录/复制，不需要你一直开着窗口。

### 步骤 7：试插一个 U 盘

插入后，状态页的「最近事件」会立刻变化；「监控记录」页点「查询」就能看到这一条；复制模式下目标目录里会出现以设备名命名的文件夹。

## 5. 日常使用：托盘、上锁、退出

### 托盘图标操作

| 操作 | 结果 |
|---|---|
| 左键单击 / 双击图标 | 打开面板；若已上锁，先弹出解锁窗口 |
| 右键单击图标 | 弹出托盘菜单 |

### 托盘菜单各项含义

```
右键托盘图标 →
┌──────────────────────────┐
│ 退出                     │  真正退出（需要输入密码）
└──────────────────────────┘
```

打开面板不放在右键菜单里：**左键单击托盘图标**即可（未解锁时先弹解锁窗口）。
托盘提示文字永远只有 `SecureVault` 一个标题，不会附加状态后缀。

如果托盘图标暂时不见了（例如开机自启时资源管理器还没准备好），程序**不会退出**，
会自动重试；这时也可以**再双击一次 exe**，让它把已有实例唤起来弹出解锁窗口。

### 开 / 关 / 退出的行为对照

| 你的动作 | 软件行为 |
|---|---|
| 关闭主面板（× 或按 Esc） | 窗口收起、**立即上锁**：要再看界面必须重新输密码；**后台监控与复制继续运行**（默认设置）；托盘图标还在 |
| 关闭后再次打开面板 | 必须**输入密码** |
| 最小化窗口（最小化按钮） | 设置里「最小化时收进托盘」开启时（默认）：收进托盘 + 上锁，后台继续运行；关闭时：普通最小化 |
| 托盘「退出程序」 | 需要**输入密码**（已上锁时先弹「退出前请验证身份」解锁，再弹一次退出确认）；确认后进程退出、托盘图标消失 |
| 开机自启（默认开启） | 启动时带 `-silent` 参数：**只驻留托盘、不弹任何窗口**，同时**自动恢复后台监控与复制**（不需要输密码） |

> 🔒 记住这句话：**「关门 = 上锁（界面）」**，但**后台照常工作**。
> 落盘数据仍然是加密的：后台运行所需的密钥副本由 Windows 用户凭据（DPAPI）保护，只在本机本用户下可解；
> 不接受这个权衡的话，去设置里关掉「关闭面板后继续在后台监控与复制」。

### 密码相关的安全机制

- 连续输错 **5 次**，会**临时锁定 60 秒**（窗口提示"失败次数过多，已临时锁定"）。
- 这个锁定状态**写在磁盘上**，关掉程序重开也依然生效。
- 解锁成功后失败计数自动清零。

```
┌─ SecureVault ───────────────────────────────────────────────────────┐
│ [状态] [监控记录] [排除名单] [定时切换] [工具] [设置] [日志]        │
│ ┌─────────────────────────────────────────────────────────────────┐ │
```

## 7. 逐页说明

### 7.1 状态

```
┌─ 运行状态 ───────────────────────────────────────────────┐
│ ┌ 运行模式（手动） ────────────────────────────────────┐ │
│ │ ( ) 复制模式（插入设备后自动增量复制）               │ │
│ │ ( ) 监控模式（只记录，不复制）                       │ │
│ │ ( ) 关闭（不监控也不复制）                           │ │
│ └──────────────────────────────────────────────────────┘ │
│ ┌ 当前状态 ────────────────────────────────────────────┐ │
│ │ 生效模式：复制模式                                   │ │
│ │ 复制目标：D:\USB备份                                 │ │
│ │ 定时计划：已启用，2 小时 后切换到「监控模式」…       │ │
│ │ 最近事件：14:22:31 接入 KINGSTON                     │ │
│ │ 最近复制：2026-09-17 14:22:40（复制 128 个 / 1.2 GB， │ │
│ │           跳过 12，失败 0）                           │ │
│ │ 规则统计：设备排除 2 条｜别名 1 条｜文件名单 4 条     │ │
│ └──────────────────────────────────────────────────────┘ │
│ [ 刷新设备列表 ] [ 应用模式 ]                            │
│ 提示：命中定时计划时以计划为准，否则使用上面的手动模式。 │
└──────────────────────────────────────────────────────────┘
```

| 控件 | 作用 | 操作后果 |
|---|---|---|
| 三个单选钮 | 选择**手动模式**：复制模式 / 监控模式 / 关闭 | 只是选中，**点「应用模式」才生效** |
| **应用模式** | 保存手动模式并立即按新规则重算生效模式 | 选「复制模式」但还没设目标目录时，会先问你要不要去设置页设置；保存失败会弹错误框 |
| **刷新设备列表** | 枚举当前所有可移动盘与本地硬盘 | 弹出一个只读窗口，列出每个盘的盘符、显示名、容量/可用、文件系统、总线、型号、VID:PID、USB 序列号、磁盘序列号；没有设备时提示"当前没有检测到可移动设备或本地磁盘" |
| 「生效模式」 | 实际正在执行的模式 | 若与手动模式不同，会注明"（定时生效中，手动为 XX）" |
| 「定时计划」 | 定时切换是否启用、下一次切换时间 | —— |
| 「最近事件」 | 最近一次接入/移除 | —— |
| 「最近复制」 | 最近一次复制的统计 | —— |
| 「规则统计」 | 排除规则 / 别名 / 文件名单 条数 | —— |

**三种模式的区别（重要）**：

| 模式 | 记录接入/移除 | 复制文件 |
|---|---|---|
| **监控模式** | ✅ 记录（处理结果显示"仅记录"） | ❌ 完全不复制 |
| **复制模式** | ✅ 记录（处理结果显示"已复制"/"出错"） | ✅ 自动增量复制到目标目录 |
| **关闭** | ❌ 接入事件不写记录（移除事件也不写）；只在日志里留一行"当前模式为「关闭」，不做任何处理" | ❌ 不复制 |

> 命中**排除名单**的设备是例外：无论当前是哪种模式（除"关闭"外），都会**记录**一条"已排除"，并且**不复制**。

### 7.2 监控记录

顶部筛选栏 + 表格 + 底部分页按钮：

```
关键词[______] 字段[全部字段▾] 事件[全部▾] 时间[全部时间▾] [查询] [重置]
┌───────────────────────────────────────────────────────────────────────┐
│ 时间 │事件│处理结果│盘符│卷标│设备型号│VID:PID│USB序列号│磁盘序列号│容量│…│
├───────────────────────────────────────────────────────────────────────┤
│ 2026-09-17 14:22:31 │接入│已复制│E:│KINGSTON│DataTraveler 3.0│0951:1666│…│
└───────────────────────────────────────────────────────────────────────┘
[上一页] [下一页] 第 1 / 1 页，共 1 条     [查看详情][加入排除名单][导出 CSV][清除记录…]
```

| 控件 | 作用 | 操作后果 |
|---|---|---|
| **关键词** | 模糊搜索（忽略大小写）。回车＝点查询 | 空＝不过滤 |
| **字段** | 限定关键词只匹配：全部字段 / 设备型号 / 卷标 / VID / PID / 序列号 / 盘符 | 选"设备型号"时同时匹配厂商字段 |
| **事件** | 全部 / 接入 / 移除 | —— |
| **时间** | 全部时间 / 最近 24 小时 / 最近 7 天 / 最近 30 天 | —— |
| **查询** | 按上面的条件重新查询 | 每页 100 条，按时间倒序（新的在前） |
| **重置** | 清空关键词、字段/事件/时间都回到"全部"，再查一次 | —— |
| **上一页 / 下一页** | 翻页 | 到底/到顶时按钮自动变灰 |
| **右键单击**某行 | 弹出菜单：加入排除名单（不再复制此设备）/ 查看详情 / 复制序列号 / 复制整行 | 复制序列号＝把 USB 序列号与磁盘序列号两行放进剪贴板；复制整行＝制表符分隔的整行文本 |
| **双击某行** | 打开「设备详情」窗口 | 只读，包含 20 多个字段（含卷 GUID、设备实例 ID、设备路径、复制统计、目标目录） |
| **查看详情** | 同上，针对当前选中行 | 没选行时无反应 |
| **加入排除名单** | 把选中行对应的设备加入设备排除规则 | 会先问「加入后：该设备插入时只记录、不复制」；加入时自动选一个最稳的匹配属性：**磁盘序列号 > USB 序列号 > 卷标 > 盘符** |
| **导出 CSV** | 选择保存位置后导出**全部**记录（最多 2 万条，不分页） | 文件带 **UTF-8 BOM**，用 Excel 直接打开中文不乱码；默认文件名 `SecureVault-监控记录-日期-时间.csv` |
| **清除记录…** | 弹出菜单：清除 7 天前 / 14 天前 / 30 天前 / **清除全部记录** | ⚠️ **不可撤销**！每次都会先弹确认框。软件**永远不会自动删除监控记录** |

> 📌 记录表里始终不显示被复制的文件清单，只有"复制文件数 / 字节数 / 耗时 / 目标目录"（在详情窗口里看）。

### 7.3 排除名单

页面分上下两块。

**上块：U 盘 / 硬盘排除规则**（命中任意一条 → 只记录、不复制）

| 控件 | 作用 |
|---|---|
| **属性** | 12 种可匹配属性（见第 10 节表格） |
| **匹配值** | 要匹配的内容；容量类填 `>=64GB` 这种表达式 |
| **备注** | 给自己看的说明（会加密存储） |
| **添加规则** | 加入规则并立即生效（不需要重启） |
| **删除选中** | 删除列表里选中的那一条（会先确认） |
| **清空规则** | 删除**全部**设备排除规则（会先确认条数） |
| **从本机磁盘快速添加…** | 弹一个当前磁盘列表，点某个盘就按"磁盘序列号 > USB 序列号 > 卷标 > 盘符"自动生成一条规则 |
| 规则列表 | 显示 类型 / 匹配值 / 备注 / 创建时间 |

**下块：文件与扩展名名单**（支持通配符 `*` 与 `?`）

| 控件 | 作用 |
|---|---|
| **名单类型** | 三选一：**排除文件/文件夹名** / **排除扩展名** / **只复制这些扩展名** |
| **值** | 文件名可写 `*.tmp`、`~$*`、`node_modules`；扩展名可写 `.tmp`、`tmp` 或 `*.tmp` |
| **备注** | 说明文字 |
| **添加** | 加入当前类型的名单并立即生效 |
| **删除选中** | 删除选中行 |
| **清空此类** | 清空当前类型的全部条目（会先确认） |
| 名单列表 | 显示 类型 / 值 / 备注 / 创建时间 |

页面底部有一行说明文字，会随"名单类型"变化，例如：

- 排除文件/文件夹名：`通配符 * 匹配任意多个字符，? 匹配单个字符；命中名称的文件或整个文件夹都会被跳过。`
- 排除扩展名：`按扩展名跳过文件，例如 .tmp、.log；大小写不敏感。`
- 只复制这些扩展名：`留空表示全部复制；一旦添加了扩展名，则只复制这些扩展名（白名单模式）。`

> ⚠️ 这三条名单**同样作用于「工具」页的桌面整理复制**（它复用同一套文件名单）。
> ⚠️ 白名单模式下，**没有扩展名的文件不会被复制**（因为它的扩展名是空的）。

## 8. 三个典型场景

### 场景 A：只想记录谁插过这台电脑（监控模式）

**目标**：只留痕，绝不往任何地方复制文件。

1. 双击 `SecureVault.exe`（首次使用请先完成第 4 节的设置密码与保存恢复码）。
2. 托盘单击打开面板，进入「状态」页。
3. 勾选「**监控模式（只记录，不复制）**」→ 点「**应用模式**」。
   - 状态栏变成：`当前模式：监控模式 ｜ 复制目标：未设置 ｜ 待机`。
4. 之后**想关就关**：关闭窗口只是收进托盘 + 上锁，后台仍在监控（默认设置）。
5. 正常插拔 U 盘/移动硬盘。每次插拔后：
   - 「状态」页「最近事件」立即更新；
   - 「监控记录」页点「查询」，能看到"接入/移除 + 仅记录"的行。
6. 需要交记录时：在「监控记录」页点「**导出 CSV**」，选保存位置。用 Excel 双击打开（UTF-8 BOM，中文不乱码）。
7. 事后想清理：点「**清除记录…**」→ 选 7/14/30 天前或全部，确认后删除（**不可撤销**）。

**说明**：监控模式不复制任何文件，但**排除名单仍然生效**——命中排除规则的设备，处理结果会显示"已排除"，备注里写明命中了哪条规则。

### 场景 B：插上 U 盘就自动增量备份到指定目录

**目标**：一插上就自动把 U 盘内容复制到 `D:\USB备份\<设备名>\`，且跳过垃圾文件。

1. 打开面板并解锁 → 进入「**设置**」页。
2. 「U 盘复制目标根目录」→「选择…」选 `D:\USB备份`（不存在会让你创建）→ 点「**保存设置**」。
3. 进入「**状态**」页 → 勾选「**复制模式**」→ 点「**应用模式**」。
4. （可选但强烈建议）进入「**排除名单**」页，添加文件级排除：
   - 名单类型选「排除文件/文件夹名」，值填 `Thumbs.db` → 「添加」；
   - 再添加 `*.tmp`、`~$*`、`System Volume Information`；
   - 名单类型切到「排除扩展名」，值填 `.log` → 「添加」。
   - 若只想备份文档，可切到「只复制这些扩展名」，依次添加 `.docx`、`.xlsx`、`.pdf`、`.jpg`（⚠️ 白名单模式下没有扩展名的文件不会被复制）。
5. （可选）如果有些设备永远不想复制（例如同事的备份盘），在「排除名单」页上半部分添加**设备排除规则**，例如：
   - 属性「卷标」+ 匹配值 `工作盘`；或
   - 属性「容量」+ 匹配值 `>=1TB`；或
   - 直接在「监控记录」页选中那台设备 → 「加入排除名单」。
6. 让面板**保持打开**（可最小化），插入 U 盘。
7. 观察结果：
   - 状态栏依次显示 `正在复制…`，然后 `上次复制 2026-09-17 14:22:40`；
   - 「状态」页「最近复制」显示"复制 X 个 / 大小，跳过 Y，失败 Z"；
   - 目标目录出现 `D:\USB备份\KINGSTON\`（文件夹名取设备名，见下）；
   - 「监控记录」页出现一条"接入 + 已复制"的记录。
8. 第二次插入同一个 U 盘：只有**新增或改动过**的文件会被复制，其余原样跳过（所以很快）。

**目标文件夹命名规则**（依次优先）：**别名**（工具 2 设置过）> **卷标** > **设备型号** > **盘符**。
名字里的 `\ / : * ? " < > |` 等非法字符会被替换成 `_`，首尾的空格和点会被去掉，超长会截断，`CON`/`NUL` 这类保留名会自动加下划线。

**空间不足时**：复制开始前会先算一遍"待复制字节数 vs 目标剩余空间"，不够就直接失败并记录（不开始复制）；复制过程中每 200 个文件复查一次，不够就**安全停止**（已复制好的文件保持有效），并在日志与记录里写明"目标磁盘剩余空间不足…已安全停止"。

### 场景 C：把桌面文件整理备份出来（工具 1）

**目标**：把桌面（含 ppt / 文档 / 图片 / 表格 / 压缩包 等）复制到备份盘，文件夹名固定为 `桌面`。

1. 打开面板并解锁 → 进入「**工具**」页。
2. 「工具 1」区域：
   - **源目录**已经自动填好桌面路径（如果不对，点「选择…」改）；
   - **目标目录**：勾选「使用与 U 盘复制相同的目标目录」就用设置页的复制目标；想单独放别处就**取消勾选**，再点「选择…」。
3. 点「**开始整理复制**」。
4. 弹出的确认框会显示"源：…／目标：…\桌面"，点「是」开始。
5. 状态文字变成"正在整理复制…"。期间：
   - 可以最小化窗口，复制在后台继续；
   - 全程静默，不会弹任何系统窗口。
6. 完成后状态文字显示：`整理完成：复制 X 个（跳过 Y，失败 Z），共 N，耗时 T 秒。 目标：D:\USB备份\桌面`。
7. 第二次运行同样只复制变化过的文件；桌面上的排除项（如果配过）依然生效。

**典型用法**：把源目录改成"下载"或"我的文档"，就变成了通用的文件夹整理复制工具。

## 9. 定时切换怎么配

**需求形态**：`HH:MM - HH:MM → 模式`，可以加任意多条；支持跨午夜；可以按星期生效。

### 例子 1：夜间自动备份，白天只监控

1. 「定时切换」页 → 起始填 `22:00`，结束填 `06:00`（**这就是跨午夜**：从当晚 22:00 一直到第二天早上 06:00）。
2. 模式选「**复制模式**」。
3. 生效日全勾（每天）。
4. 备注填"夜间自动备份"→ 点「**添加**」。
5. 再加一条：起始 `09:00`，结束 `12:00`，模式「监控模式」，生效日勾周一到周五，备注"上班时段只监控"→「添加」。
6. 确认顶部「**启用定时切换**」是勾上的，并且「设置」页的同名选项也是勾上的（两者联动）。
7. 底部预览区会显示：`当前生效模式：… ；下一次切换：2 小时 后切换到「监控模式」（09:00 - 12:00）`。

### 例子 2：只有周末才复制

起始 `00:00`、结束 `23:59`、模式「复制模式」、生效日只勾「六」「日」。

### 规则细节

- 命中任一时间段时，**以计划为准，忽略手动模式**；状态栏会写成 `当前模式：监控模式（手动 复制模式）`，状态页会写"（定时生效中，手动为 XX）"。
- 没有命中任何时段 → 回到「状态」页选择的手动模式。
- 软件每 20 秒重算一次，所以切换最多有 20 秒的延迟。
- 形式为 `START = END` 的时段（例如 `08:00` - `08:00`）表示**全天**。
- 跨午夜的时段，后半段（00:00 ~ 结束时间）按**前一天**的星期生效。例如"周五 22:00 - 06:00"，周六凌晨 0~6 点仍在计划内。
- 时间段之间若重叠，取列表里排在前面的那条（列表按起始时间排序）。
- 想临时停用某条计划？目前必须**删除**它（或在「设置」/本页关掉总开关）。新增的计划默认就是启用状态。

## 10. 排除规则怎么写

### 10.1 设备排除规则（12 种属性，规则之间是"**或**"）

命中任意一条 → 该设备插入时**只记录、不复制**。

| 属性（界面名） | 匹配值怎么写 | 匹配方式 |
|---|---|---|
| 总线类型 | `USB`、`SATA`、`NVMe` | 完全相等（忽略大小写） |
| USB 厂商 ID | `0951` | 等于 VID；写成 `0951:1666` 也认 |
| USB 产品 ID | `1666` | 完全相等 |
| USB 序列号 | `60A44C4136B0F0B1` | 完全相等 |
| 磁盘序列号 | `5CDF_B803_81A0_4EE8.` | 完全相等 |
| 设备型号 | `Kingston DataTraveler 3.0`、`SanDisk*` | 完全相等 **或**通配符匹配（支持 `*` `?`） |
| 卷标 | `工作盘`、`BACKUP*` | 完全相等 **或**通配符匹配（支持 `*` `?`） |
| 文件系统 | `NTFS`、`exFAT`、`FAT32` | 完全相等 |
| 盘符 | `E` 或 `E:` | 两种写法都认 |
| 物理磁盘号 | `1` | 等于该数字 |
| 设备实例 ID | `USBSTOR\DISK&VEN_KINGSTON` | 完全相等 **或**包含（忽略大小写） |
| 容量 | `>=64GB`、`<=2GB`、`512MB` | 见下 |

**容量表达式**：

| 写法 | 含义 |
|---|---|
| `>=64GB` | 大于等于 64 GB |
| `>64GB` | 大于 64 GB |
| `<=2GB` | 小于等于 2 GB |
| `<2GB` | 小于 2 GB |
| `512MB` 或 `=512MB` | 约等于 512 MB（允许 ±2%，最少 ±64 MB 的容差，避免"标称 64GB 实际 63.9GB"不命中） |

单位支持 `B` / `KB` / `MB` / `GB` / `TB`（也可只写 `G`、`M`、`T`），大小写不敏感。

**操作后果**：添加/删除/清空规则后**立即生效**，不需要重启，也不需要重新插入设备（已经插着的设备不会被追溯处理，下次插拔时才判定）。规则内容（匹配值、备注）都会加密存储。

### 10.2 文件 / 文件夹名排除（支持通配符）

- 「名单类型」选「**排除文件/文件夹名**」，「值」里填：
  - `*.tmp` —— 所有 `.tmp` 结尾的名字；
  - `Thumbs.db` —— 精确名字；
  - `~$*` —— Office 临时文件；
  - `node_modules` —— 命中**文件夹名**时，**整个文件夹（含子目录）都会被跳过**；
  - `?ache` —— `?` 匹配任意**单个**字符（例如 `cache`、`Cache`…）。
- 匹配**只看名字本身**，不匹配完整路径；`*` 和 `?` 都**不跨越** `\`。
- 大小写不敏感。

### 10.3 扩展名

- 「**排除扩展名**」：填 `.tmp`、`tmp` 或 `*.tmp` 都行（程序会统一成 `.tmp` 再比较），大小写不敏感。
- 「**只复制这些扩展名**」（白名单）：一旦这个类别里**有任何一条**，就只复制这些扩展名；留空（一条都没有）＝全部复制。
- 规则优先级：先判断"排除扩展名"，再判断白名单。
- ⚠️ 白名单模式下，**没有扩展名的文件不会被复制**。

## 11. 工具 2：设备别名

**作用**：给某台设备起一个你自己看得懂的名字，它会同时改变两处：

1. 「状态」页设备列表、监控记录里显示的**设备名**；
2. 复制时生成的**目标文件夹名**。

**怎么用**（「工具」页 → 工具 2 区域）：

| 控件 | 说明 |
|---|---|
| **匹配属性** | 卷标 / 设备型号 / USB 厂商 ID / USB 产品 ID / USB 序列号 / 磁盘序列号 / 设备实例 ID |
| **匹配值** | 与所选属性完全相等（忽略大小写） |
| **别名** | 要显示与命名的名字，不能为空 |
| **备注** | 说明文字 |
| **添加别名** | 新增一条别名规则并立即生效 |
| **保存修改** | 把表单内容保存到列表里选中的那条 |
| **删除选中** | 删除选中的别名（会先确认） |
| 别名列表 | 显示 匹配属性 / 匹配值 / 别名 / 备注 |
| 点击某行 | 把该行内容填回表单，方便修改 |
| 行上右键 | 「用本机磁盘填充匹配值…」（从当前磁盘列表里点一个，自动把对应属性的值填进"匹配值"）/「复制匹配值」 |

**命名优先级**：**别名 > 卷标 > 设备型号 > 盘符**。

**操作后果与注意事项**：

- 匹配是**完全相等**（忽略大小写），不支持通配符；属性要选对（例如按"磁盘序列号"匹配最稳，换 USB 口也不会变）。
- 改别名后**下一次复制**才会写进新文件夹名；**旧文件夹不会被重命名或删除**，历史备份留在原处（这是有意为之，避免误删数据）。
- 如果两条别名的匹配值指向同一台设备，按数据库返回顺序取**第一条**（可能会让人困惑，尽量避免重复）。
- 识别不准时，用「状态」页的「刷新设备列表」查看每台设备的真实属性值，再回到这里填。

## 12. 日志与监控记录

### 日志

| 项目 | 说明 |
|---|---|
| 形式 | **纯文本** `txt`，**一天一个文件**，文件名 `YYYY-MM-DD.txt` |
| 位置 | `SecureVaultData\logs\` |
| 编码 | UTF-8，行尾 CRLF（Windows 记事本可直接打开） |

| 手动清理 | 「日志」页：**清除 7 天前** / **清除全部日志** |
| 内容 | 启动/退出、上锁/解锁、模式切换、定时计划命中、设备接入/移除、复制开始/完成/失败明细（最多 20 条）、设置变更等 |

### 监控记录

| 项目 | 说明 |
|---|---|
| 存储 | 加密数据库 `vault.db`（敏感字段用 AES-256-GCM 加密后存二进制） |
| 每条记录 | 时间、事件（接入/移除）、处理结果、盘符、卷标、总线类型、型号、厂商、VID、PID、USB 序列号、磁盘序列号、文件系统、容量、剩余、物理磁盘号、设备实例 ID、卷 GUID、设备路径、可移动、复制文件数/字节数/耗时/目标目录、备注 |
| 自动删除 | ❌ **永远不会自动删除**。只有你在「监控记录」页点「清除记录…」才会删（7 天前 / 14 天前 / 30 天前 / 全部） |
| 搜索 | 关键词（可限定字段）+ 事件类型 + 时间范围 + 分页（每页 100 条），也可以点击表头排序 |
| 导出 | **导出 CSV**，带 UTF-8 BOM → Excel 打开中文不乱码；一次最多导出 2 万条 |

> 说明：关键词搜索是在解密后于内存中进行的，所以搜索范围最多覆盖最近的 2 万条记录。

## 13. 忘记密码怎么办

### 情况一：还有恢复码（可以救回来）

1. 打开面板（托盘单击）。
2. 在解锁窗口点左下角的「**忘记密码 / 用恢复码重置**」。
3. 填写：
   - **恢复码**：`XXXX-XXXX-XXXX`，**大小写、横线、空格都不敏感**（`7k2m9qxa4b1z` 也认）；
   - **新密码** + **确认新密码**（≥8 位，两次一致）。
4. 点「**重置**」。
   - 恢复码不对 → 提示"恢复码不正确"；格式不对 → 提示"恢复码格式不正确，应为 XXXX-XXXX-XXXX"；连续失败同样会触发 60 秒冷却。
5. 成功后**立刻弹出新的恢复码**（旧的**立即失效**），同样**只显示这一次**，请重新抄写保存。
6. 用新密码解锁进入。

### 情况二：密码和恢复码都丢了

> ❌ **无解。数据永久无法解密。**

- 程序**没有后门**，也不保存密码或恢复码的任何明文；`keystore.json` 里只有用密码/恢复码派生的密钥加密后的主密钥。
- 唯一"恢复"办法：删除 `SecureVaultData` 目录重新初始化（**已记录的历史全部丢失**）。

### 情况三：只是想改密码（还记得当前密码）

「设置」页 →「**修改密码**」→ 输入当前密码、新密码（两次）→ 确定。**恢复码保持不变**，可以继续用。
如果想换一个恢复码：「设置」页 →「**重新生成恢复码**」→ 确认 → 输入当前密码 → 抄下新码（旧码立即失效）。

## 14. 常见问题 FAQ

**1. 托盘里找不到图标了？**
先看任务栏右下角的"隐藏的图标"折叠区（^）。另外：资源管理器（explorer.exe）重启后图标可能会消失，本程序会自动重新添加；若还是看不到，用任务管理器确认 `SecureVault.exe` 是否在运行，没有就重新双击启动（已有一个实例在跑时，重复启动会自动激活它并退出新进程）。

**2. 插了 U 盘，为什么什么都没复制？**
按这个顺序排查：
1. 「状态」页看**生效模式**：是「关闭」吗？是「监控模式」吗？→ 切成「复制模式」并点「应用模式」；
2. 复制目标是不是空的？→ 到「设置」页设置并保存；
3. 设置页的「**关闭面板后继续在后台监控与复制**」是不是被关掉了？→ 关掉后只有面板开着才会监控；
4. 设备是否命中**排除规则**？→ 到「监控记录」页看这条记录的处理结果：显示"已排除"就是命中了，备注会写明是哪条规则；
5. 文件是否被**名单**过滤掉了？→ 检查「排除名单」页的文件名/扩展名/白名单（白名单模式下没有扩展名的文件不会被复制）；
6. 目标目录和 U 盘是不是同一个盘？→ 增量索引会导致行为异常，请换成别的盘上的目录；
7. 都正常？→ 看「日志」页当天的日志，复制失败原因都写在里面。

**3. 提示"目标磁盘剩余空间不足"会怎样？**
- 复制**开始前**：算出让待复制总字节数 > 目标剩余空间，就直接判定失败，**一个文件都不会复制**，并在监控记录/日志里记一条"目标磁盘剩余空间不足，需要 X，可用 Y"。
- 复制**过程中**（每 200 个文件复查一次）：发现剩余空间不够就**安全停止**，已经复制好的文件保持有效，剩余的不再复制；日志里写明"已安全停止；已复制的文件保持有效"。
- 处理办法：清理目标盘空间，然后重新插拔设备（或再次触发）即可继续增量复制，不会重复拷已完成的部分。

**4. 能不能把 exe 放到 U 盘里带着走？**
可以。数据目录 `SecureVaultData` 会跟着 exe 走，插到别的电脑上双击就能用。注意：每台电脑上的密码是**各自独立**的（数据不共享）；另外请确认目标电脑允许在 U 盘上创建文件（有些受管控的电脑会禁止）。

**5. 会不会往 C 盘写东西？**
- 数据（密钥库、数据库、日志、临时文件）**全部**写在 exe 同级的 `SecureVaultData\` 里。
- **不写注册表**。
- 唯一的例外：开启"开机自动启动"时会创建 `C:\Users\<你>\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\SecureVault.lnk`（这是需求指定的实现方式，随时可在设置里关闭或手动删除）。

**6. 关掉窗口后，它还在后台监控/复制吗？**
**在。** 关闭窗口只是把**界面**收进托盘并上锁（要再看界面必须重新输密码），
**后台的监控与复制继续运行**；开机自启（`-silent`）也会自动恢复后台运行，不需要输密码。

如果你希望"关闭窗口就彻底停下来"，到「设置」页取消勾选「**关闭面板后继续在后台监控与复制**」并保存：
那样上锁会停引擎、关闭数据库、清空内存里的密钥（代价是重启后必须先打开面板解锁才会开始监控）。

**7. 怎么彻底卸载？**
1. 右键托盘图标 →「退出程序」→ 输入密码，确认退出（或直接用任务管理器结束 `SecureVault.exe`）；
2. 删除 exe 所在文件夹（连同 `SecureVaultData`）；
3. 删除 `C:\Users\<你>\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\SecureVault.lnk`（或在删除前先在设置里关掉"开机自动启动"）。
没有其它残留。

**8. 为什么第二次插同一个 U 盘，几乎没有进度就"完成"了？**
因为用的是**增量复制**：程序记录了上次复制过的每个文件的**大小 + 修改时间**，两者都没变就直接跳过。所以你新加/改过的文件会被复制，没动过的原样保留（也不重复占用时间）。注意：如果只改了文件内容、但大小和修改时间都没变（极少见），会被判定为"没变化"而跳过。

**9. 复制时会弹进度框或 cmd / PowerShell 黑窗吗？**
不会。复制、扫描、错误处理**全程静默**，不调用 cmd / PowerShell / robocopy，也不弹任何系统窗口。进度只在主面板状态栏与状态页显示（"正在复制…"）。

**10. 为什么"移除"事件没有记录？**
「设置」页的「**记录设备移除事件**」被关掉了，或者当时的模式是「关闭」。打开这个选项后，之后的移除事件都会记录。

**11. 日志会被自动删，监控记录也会吗？**
不会。日志按保留策略（7/14/30 天，默认 14 天）自动清理；**监控记录只会因为你手动执行"清除记录"而删除**。

**12. 「目标目录当前不存在」怎么办？**
保存设置时会问你是否创建，点"是"就自动创建（支持超过 260 字符的长路径）。工具 1 里若目标为空，会提示"尚未设置目标目录"。

**13. 改了别名，为什么旧文件夹还在？**
命名只在**下一次复制**时生效，程序**不会**重命名或删除历史文件夹（避免误删你的备份）。想要统一命名，请自己手动处理旧文件夹。

**14. 支持网络盘、光驱、读卡器吗？**
只监控**固定磁盘和可移动磁盘**（本地硬盘、U 盘、移动硬盘、部分读卡器）。光驱、网络映射盘、RAM 盘不参与监控。插着空读卡器时读不到卷信息，会被跳过。

**15. 提示"失败次数过多，已临时锁定"是什么？**
连续输错密码（或恢复码）5 次后，会锁定 **60 秒**；这个状态写在磁盘上，**重启程序也照样生效**。等 60 秒后再试，或者用恢复码重置。

**16. 面板上的「最小化时收进托盘」勾了好像没反应？**
现在这个选项**真的会生效**：勾选（默认）时，**最小化窗口＝收进托盘 + 上锁**（后台监控照常运行）；
取消勾选则是最普通的"最小化到任务栏"。

**17. 界面上的字/卡片看起来挤在一起，或者有些内容看不到？**
窗口拉小之后，页面会按"最小内容高度"排版，**用鼠标滚轮或 PageDown 往下滚**就能看到下面的内容
（右侧有细滚动条）。如果你看到两块内容明显压在一起（重影），那属于排版缺陷，请反馈并附上当时的窗口尺寸。

**18. 托盘的图标和 exe 的图标是同一个吗？**
是。`assets\securevault.ico` 既通过 `//go:embed` 打进程序内部（托盘图标、窗口标题栏图标），
也由 `scripts\addmanifest` 作为 PE 图标资源写入 exe（资源管理器里看到的图标）。

## 15. 安全提示

1. **密码不要用生日、手机号、`12345678`、连续键盘**。≥8 位、混用大小写字母+数字+符号更安全。
2. **恢复码单独保存**：别和备份出来的文件放在同一个 U 盘/目录里，否则一起丢。推荐：手抄一份放抽屉 + 密码管理器里存一份。
3. **不要把 exe 放在只读目录**（只读光盘、受保护的系统目录）：程序无法创建数据目录会直接退出。
4. **不要把 `SecureVaultData` 放进云盘同步目录**：数据库在复制过程中被同步可能损坏；加密数据也没有必要同步。
5. **离开电脑前上锁**：按 `Esc`、关闭面板（×）或最小化窗口。上锁后**面板**必须用密码才能打开；
   如果连后台运行也不想留，去设置页关掉「关闭面板后继续在后台监控与复制」，那样上锁会同时清空内存密钥、关闭数据库。
6. **注意"何时在监控"**：默认设置下**一直在监控**（面板关着也照常跑），重启后也会自动恢复；
   这条能力依赖"由 Windows 用户凭据（DPAPI）保护的密钥副本"，只在本机本用户下可解。
7. **别在公共电脑上长期挂着解锁状态的面板**：任何能操作这台电脑的人都能看到记录、改规则。
8. **恢复码等于第二把钥匙**：谁拿到它，谁就能重置密码并解密全部数据。

| `-silent` | 静默启动：只驻留托盘，不弹任何窗口（开机自启快捷方式用的就是它） |
| `-debug` | 额外输出 DEBUG 级日志（默认不写调试信息） |
| `-help` / `-h` / `/?` | 在控制台显示帮助并退出 |
| `-review` | **开发/测试选项**：写入演示数据后直接打开主面板，跳过密码流程 |
| `-autotest` | **开发/测试选项**：跑一遍真实流程（设密码 → 解锁 → 开面板 → 上锁 …）并把结果写入 `SecureVaultData\autotest.log` |

> exe 是 GUI 子系统程序，双击运行不会出现控制台窗口；`-help` 的输出需要从命令行（cmd / PowerShell）运行才能看到。

> ⚠️ `-review` 与 `-autotest` 只给开发和验收用：它们会**绕过密码**或**改写/重置你的密钥库**，请勿对着正式数据运行。

### 16.2 数据目录里的文件

| 文件 | 内容 | 能不能删 |
|---|---|---|
| `keystore.json` | KDF 参数（算法/迭代次数/salt）、密码与恢复码各自包裹后的主密钥、校验值、失败次数与锁定截止时间 | ❌ 删了＝数据无法解密（等同重置一切）；文件损坏时可删除后重新初始化 |
| `vault.db`（+ 运行时 `-wal` / `-shm`） | 监控记录、排除规则、文件名单、别名、定时计划、设置、增量索引 | ❌ 删了＝历史记录与设置全部丢失 |
| `logs\YYYY-MM-DD.txt` | 当天日志 | ✅ 可随时删（软件自己也会按保留策略清理） |
| `tmp\` | 写文件时的临时文件、启动时的可写性探测文件 | ✅ 可随时删（程序不运行时） |

### 16.3 快捷操作速查

| 想要的效果 | 操作 |
|---|---|
| 打开面板 | **托盘左键单击**（或再双击一次 exe 激活已有实例），未解锁时先输密码 |
| 立即上锁 | 关闭面板（×）、面板里按 `Esc`、最小化窗口，或设置页「立即上锁」 |
| 刷新状态 | 面板里按 `F5` |
| 只要留痕不复制 | 状态页 → 监控模式 → 应用模式 |
| 只在插入时自动备份 | 设置页设目标 → 状态页选复制模式 → 应用模式 |
| 只备份某一类文件 | 排除名单页 →「只复制这些扩展名」 |
| 让某台设备永不被复制 | 监控记录页选中该设备 →「加入排除名单」 |
| 交出一份记录 | 监控记录页 →「导出 CSV」 |
| 换个恢复码 | 设置页 →「重新生成恢复码」 |
