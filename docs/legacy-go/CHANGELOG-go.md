## [v1.0.5] - 2026-09-18

按"很多按钮被遮挡 / 输入框压住按钮 / 很多东西显示不出来 / 还是原生样式 / 日志页滑动仍有重叠"的反馈，
把整个界面重新做了一遍几何审查，并修掉两类根因。

### Fixed

**输入框压住按钮、按钮被遮挡（真实缺陷，已用工具逐页量出来）**
- 排除名单页：备注输入框太长，直接压在「添加规则」「从本机磁盘快速添加…」上面。
- 工具页：别名输入框太长，压在「添加别名」上。
- 监控记录页：分页信息标签写死宽度，窗口一窄就压到「查看详情」上。
- 排除名单页：底部说明文字固定在页面底端，窗口变矮时压在「删除选中」按钮上。
- 修法：右侧按钮区宽度统一由 `buttonsRightWidth()` 计算后再给输入框预留空间；
  分页标签宽度改成"剩下的空间"；说明文字改为跟着内容流走。
- **新增断言**：`-autotest` 现在会**逐页切换后**检查"同页控件互不重叠"（以前只检查当前页，
  所以这些重叠全被漏掉了），并在"窗口压到最小 + 滚到底"的状态下再查一遍。

**界面比窗口还大 → 控件互相遮挡、右边/下边被切掉（"很多东西显示不出来"的根因）**
- 界面缩放系数取自 `GetDpiForSystem()`。当**系统 DPI 与显示器实际 DPI 不一致**时
  （多显示器、改过缩放、远程桌面等），界面会按 1.5 倍排版而窗口只有 1200×800 像素，
  于是所有控件都比窗口大一圈：互相压住、看不见。
- 现在：① 用 `GetDpiForWindow()`（窗口所在显示器）确定缩放；
  ② 主面板启动时按屏幕工作区**向下钳制缩放**，保证默认窗口（1200×800 DIP）一定放得下；
  ③ `WM_DPICHANGED` 后立即按新缩放重排。

### Changed

- **所有控件自绘、直角、扁平**：按钮（浅灰直角 + 悬停/按下/禁用/焦点状态）、
  复选框（直角方框 + 强调色勾）、单选框（圆点）、输入框（1px 直角边框，替代 Win95 凹陷边框）、
  卡片（白色直角 + 1px 描边）。**下拉框保留系统主题绘制** —— 它本来就是 Win10 那种白底细边框，
  而自定义绘制实测会画成空白（COMBOBOX 的绘制路径和普通控件不同），不值得冒险。
- 所有自绘控件都支持 `WM_PRINTCLIENT`，截图/审计工具能看到真实外观。

### Added

- `scripts\uiaudit`：**逐页几何审查工具**，列出每个可见控件的坐标，报告"越界 / 互相重叠 /
  被裁成空区域"，并可自动逐页切换（`uiaudit 0 1 2 3 4 5 6`）。DPR 感知，150% 下量的是真实像素。
- `scripts\wincap` 新增 `--rows` / `--darkrows` / `--rectstats` / `--rectclient` / `--scrollcheck`
  模式：在没有肉眼的环境里也能判断"控件里到底有没有画出文字""滚动会不会画到别的区域"。

### Verified

- `uiaudit 0 1 2 3 4 5 6`（150% DPI，真实像素）→ **7 个页面全部无越界、无重叠、无空区域**。
- `SecureVault.exe -autotest` → **98 项通过 / 0 项失败**（含逐页重叠检查、滚动到底后的重叠检查）。
- `scripts\e2e` → **25 项通过 / 0 项失败**（真实点击 + 点击压力测试 + 托盘去重）。

## [v1.0.4] - 2026-09-18

**紧急修复 v1.0.3 引入的回归**（用户反馈"输密码进去之后点都点不了、一圈大黑框、显示不全、点几下崩溃"）。
这一版还把所有按钮换成了自绘扁平样式，并给界面加上"崩溃兜底"。

### Fixed

**回归 1：进去之后控件看不见、也点不到**
- 根因：`ClearClipRect()` 用 `CreateRectRgn(0,0,0,0)`（**空区域**）来"恢复"窗口裁剪，
  等于把控件裁成 0 面积。`IsWindowVisible` 仍然返回 true，所以之前所有断言都查不出来，
  但屏幕上看不见、鼠标也点不中（`SetWindowRgn(hwnd, NULL, ...)` 才是真正的恢复）。
- 这是 v1.0.3 新增"页面滚动裁剪"时踩到的老 API 误用。现已修正，
  并新增断言 **"没有控件被裁剪成不可见/不可点"**（用 `GetWindowRgn` + `GetRgnBox` 逐控件核对）。

**回归 2：窗口四周一圈大黑框**
- 根因：自绘窗口的 `WM_ERASEBKGND` 被有意关掉（返回 1，为了双缓冲不闪烁），
  但重绘时只填了"内容区"，内容区以外的部分（左右边距、标签条下方、底部状态栏那一条）
  **从来没有被绘制过**，保留的是未初始化内容 —— 显示为黑色。
- 现在重绘时**先把整个客户区铺满底色**，再画内容区/卡片/滚动条。截图统计：黑色像素 4.0% → 0.9%（只剩文字与边框）。

**回归 3：点几下就崩溃（栈溢出）**
- 根因：自绘按钮的 `WM_GETDLGCODE` 处理里又调了一次 `dispatchMessage`，
  而它正是当前正在执行的函数 —— 无限递归 → 栈溢出 → 进程直接消失。
  （这一条是新增的"点击压力测试"抓出来的：它会把每个页面上的按钮都点一遍。）

### Changed

- **按钮现代化**：所有按钮改为自绘扁平样式（浅灰圆角底 + 细边框 + 居中文字，
  悬停变深、按下更深、禁用变灰、获得焦点显示强调色描边）。
  实现方式是标准子类化 + `CallWindowProc` 交回原窗口过程，所以
  `BM_CLICK`、键盘空格/回车、Tab 导航、无障碍等标准行为保持不变。
- **崩溃兜底**：窗口过程（`ui.wndProc`）、托盘/设备消息回调（`App.onMessage`）、
  复制 goroutine（`engine.runCopy`）、设备事件循环、设备广播窗口过程全部加了 `recover()`。
  界面回调里的一个 panic 从此只会写进日志，不会再"整个程序消失"。
- **上锁不再在窗口自己的消息处理里销毁窗口**：改为"先隐藏 + 把销毁排到消息队列"，
  避免"在窗口自己的消息过程里 `DestroyWindow`"这类经典崩溃。

### Added

- `scripts\e2e` 新增 **点击压力测试**：逐页把每个按钮都点一遍（一半用 `BM_CLICK`、
  一半用"真实鼠标按下/抬起"）、随后滚轮上下滚动、再点一次「立即上锁」，
  全程断言进程存活、主面板状态正确。25 项断言。
- `-autotest` 98 项（新增"没有控件被裁剪成不可见/不可点"）。
- `ui/win`：`CallWindowProc`、`TrackMouseLeave`、`WindowRgnIsEmpty`；
  自绘控件支持 `WM_PRINTCLIENT`（截图工具也能拍到按钮/卡片/标签条）。

## [v1.0.3] - 2026-09-18

按"界面太老、点托盘弹出两个窗口、有些页面不能滚动、日志页有重影、要加图标"的实机反馈做的界面与交互修复。

### Fixed

**点托盘弹出两个重叠的窗口**
- 一次鼠标左键单击在 `NOTIFYICON_VERSION_4` 下会同时产生 `WM_LBUTTONUP` 与 `NIN_SELECT` 两条通知；
  第二个进程的"激活已有实例"广播也可能在**模态窗口自己的嵌套消息循环**里被派发。
  旧代码每次都直接开一个新窗口，于是"点一次托盘 / 连点两次 exe"会叠出 2~4 个完全重合的窗口。
- 现在有三道闸：`App.activating`（正在打开流程）、`App.modalDepth`（已有模态窗口在开）、
  以及 400ms 内的重复激活去重。`scripts\e2e` 里新增断言"连续快速启动多次只出现一个窗口"。

**切换标签页时页面内容重叠**
- 反向点标签时残留其他页控件的问题，`-autotest` 现在正向/反向、代码跳页/真实点击四条路径逐一核对
  "只有当前页的控件可见"。
- 顺带修掉一个更隐蔽的排版缺陷：卡片高度在多次布局之间会**累积**（`Card.Rect.Bottom` 只增不减），
  窗口放大一次再缩小，卡片仍然保持大高度，下面的内容被一路顶出可视区/压到一起。
  现在非固定高度的卡片每次布局都会重置高度。

**有些页面不能上下滚动**
- 以前页面内容比窗口高时只能被裁掉（底部按钮点不到）。现在每个页面声明"最小内容高度"，
  窗口不够高时按最小高度排版，**鼠标滚轮 / PageUp / PageDown / Home / End / ↑ / ↓** 都能滚动，
  右侧还有一条细滚动条指示位置；滚出可视区的控件会被裁剪，不会盖到标签条或状态栏上。
- `-autotest` 新增"把窗口压到最小尺寸后，每个页面都能滚到看到最底部控件"的断言。

**日志页上下滑动有重影**
- 日志页的预览框在窗口偏矮时会与底部按钮重叠（布局里的最小高度下限会把它推到按钮上），
  两块内容叠在一起看起来就是"重影"。现在页面按最小内容高度排版 + 控件互不重叠由断言守住。
- 主窗口改为**双缓冲绘制**（先画到离屏位图再一次性 BitBlt），列表控件启用 `LVS_EX_DOUBLEBUFFER`，
  滚动/切页/缩放不再闪烁残影。

**界面观感太老（改为 Win10 风格）**
- 窗口底色从系统"对话框灰"改成白色；系统 `BS_GROUPBOX` 蚀刻边框换成**自绘白色卡片**（细边框 + 加粗标题）。
- 顶部标签条从系统 `SysTabControl32` 换成**自绘扁平分段栏**：浅灰轨道 + 选中白块 + 底部强调蓝条 + 加粗文字。
- 列表去掉老式网格线，保留整行选中；状态栏只留一条细分隔线。
- 统一配色（白底 #FFFFFF / 浅灰 #F3F3F3 / 描边 #E0E0E0 / 文本 #1F1F1F / 强调 #0078D7）。

**exe 没有图标**
- `scripts\addmanifest` 现在除了注入清单，还会把 `assets\securevault.ico` 作为
  `RT_GROUP_ICON` + `RT_ICON` 资源写进 PE（纯 Go 构造 `.rsrc` 的完整资源目录树），
  资源管理器 / 任务栏 / 标题栏都能看到应用图标。

### Added

- `-autotest` 断言 68 → **97 项**：新增"各页面的增/删/改/清空全部走一遍"（排除规则、名单、定时计划、
  设备别名、记录查询、CSV 导出、桌面整理、设置保存、日志预览）、"同页控件互不重叠"、"列表列宽不溢出"、
  "反向切页不残留"、"窗口变矮时可滚动"。
- `ui.SetAutoAnswer(true)`：自动验收时确认框一律按"是"处理（只在 `-autotest` 里开启）。
- `scripts\wincap` 支持打印颜色统计（无肉眼环境也能核对界面配色是否真的生效）。
- 引擎导出 `MatchExclude()`，供界面提示与自检复用同一套排除判定。

### Changed

- `internal/ui` 增加主题色（`ui.T.*` / `ui.ColorXxx()`）、`Form.MouseWheel`、`Form.SetQuitOnDestroy`、
  `Form.Minimized`、双缓冲绘制。
- README 第 5 节（界面说明）、第 10 节（测试）、第 12 节（已知限制）与 `docs\使用手册.md` 同步更新。

## [v1.0.2] - 2026-09-18

按"装上就用不起来"的实机反馈修复。**核心是四个致命缺陷**：关掉面板会把整个程序带走、托盘创建失败就退出、
关掉面板后完全不再自动复制、监控记录列表在 150% 缩放下少一半列。修复后新增"真实点击"的端到端界面验收。

### Fixed

**致命：关掉面板 = 整个程序退出**
- 主面板销毁时会 `PostQuitMessage`，于是"关闭窗口（×）→ 收进托盘"实际变成"关闭窗口 → 程序退出、托盘图标消失"，
  用户完全没法把它当后台工具用。现在 `ui.Form` 增加 `SetQuitOnDestroy(false)`，主面板销毁只销毁窗口，
  进程继续驻留托盘（只有托盘「退出」才结束进程）。由 `scripts\e2e` 用真实窗口消息复现并回归。

**致命：托盘图标创建失败 → 直接退出**
- 开机自启时 Explorer 可能还没把通知区域准备好，`Shell_NotifyIcon` 会失败。旧实现弹一个错误框然后 `return 5` 退出，
  用户看到的现象就是"开机后程序不见了"，而且在非交互会话里那个模态框还会把流程卡死。
  现在：托盘创建失败只记日志，程序继续运行并**在心跳里每秒重试**（`retryTray`），
  15 次仍失败且处于可交互会话时才提示一次；同时"再运行一次 exe"可以唤醒已有实例弹出解锁窗口。

**致命：关掉面板后引擎被停掉，"插上 U 盘自动复制"只在面板开着时有效**
- 旧实现把"上锁"等同于"停引擎 + 关数据库 + 清空内存密钥"，而程序默认就是常驻托盘、面板关闭，
  于是自动复制形同虚设。现在默认**关闭面板后后台监控与复制继续运行**（设置页可关掉，恢复旧的严格行为）。
- 为了让开机自启后不需要输密码也能恢复后台监控，`keystore.json` 里会保存一份由
  **Windows 用户凭据（DPAPI）**保护的 DEK 副本（`AutoUnlock`）。密码与恢复码仍然不落盘，
  副本只在本机本用户下可解；设置里关闭"后台监控"会立即删除这份副本。
- 界面安全语义不变：打开面板、改密码、重新生成恢复码、退出程序都仍然必须输入密码。
- `afterUnlock` / `startCore` 拆开：打开面板不再重复打开数据库；`autoResumeBackground` 在启动时静默恢复后台运行。

**监控记录列表少一半列（150% 缩放）**
- `page_records` 里列宽被缩放两次（`ui.L(L(n))` 的残留写法），150% 下列宽放大 1.5 倍，
  后面的"USB序列号/磁盘序列号/备注"等列被挤出列表可视区。
  `-autotest` 新增硬断言"所有列宽之和必须放得进列表宽度"，逐页、逐列表核对。

**其它**
- `ui.Form.SetMinSize` 把最小尺寸写进了**包级全局变量**，任何窗口设置过都会影响所有窗口；改为每个窗口自己的字段。
- 主面板初始 1200×800 DIP 会超出小屏幕工作区（例如 1920×1080 @150% 时窗口高 1200 像素），
  底部按钮/状态栏被挡在屏幕外。现在会按 `SPI_GETWORKAREA` 自动缩小（最小 900×580 DIP）。
- 设置页的「最小化时收进托盘」以前是个没有实现的死开关；现在最小化窗口真的会收进托盘并上锁。
- 开发开关 `-review` / `-autotest` 改用**独立数据目录 `SecureVaultData-dev\`**：
  评审模式会造演示数据、必要时还会重建密钥库，绝不能再碰用户的正式加密库。
- 新增 `scripts\wincap`（用 `PrintWindow` 抓窗口，没有可读桌面时也能验收排版）。

### Added

- `scripts\e2e`：**真实点击**的端到端界面验收（22 项）。它不调用内部函数，而是用窗口消息驱动真实界面：
  首次设置密码（含"两次不一致被拒绝"）→ 恢复码窗口（校验格式）→ 二次确认 → 主面板 →
  用方向键切到「设置」页填目标目录并保存（含"目录不存在 → 确认创建"）→ 切回「状态」页应用复制模式 →
  关闭面板（断言进程仍在、日志显示后台继续）→ 再次运行 exe 激活实例 → 错误密码被拒 → 正确密码打开面板。
- `-autotest` 断言 34 → **68 项**，新增覆盖：关掉面板后引擎/数据库仍在、**关面板后插入设备真的会复制**
  （真实文件、子目录、中文名、空文件、监控记录）、列表列宽不溢出、
  关闭"后台监控"后上锁必须彻底停止并清空密钥、**模拟重启后自动恢复后台引擎**。
- `internal\keystore\autounlock_test.go`：自动解锁的往返、重启可用、被篡改必须失败。

### Changed

- 托盘图标创建失败不再返回退出码 5（退出码 5 现在只表示"消息窗口创建失败"）。
- README 第 3.4 / 3.5 / 5.3 / 6.4 / 8 / 10 / 12 / 13 节按新行为重写。

## [v1.0.1] - 2026-09-17

按实机验收反馈修复可用性问题。**核心是把"打开主面板一片空白"彻底修掉** —— 根因是 6 个叠加缺陷。

### Fixed

**界面完全不可用（最重要）**
- **主面板打开后一片空白**：页面容器窗口漏了 `WS_VISIBLE`（`WS_CHILD` 常量把 `WS_CLIPCHILDREN/WS_CLIPSIBLINGS` 顶掉时一起丢的），
  容器创建出来就是隐藏的，导致整棵控件子树不可见。现已在 `NewPage` 显式加 `WS_VISIBLE`，
  并在 `Form.create` 加兜底断言（期望可见却不可见时补一次 `ShowWindow`）。
- **系统 Tab 控件与页面互相遮挡**：Tab 控件会把整个矩形画成灰底，与页面容器重叠时必然遮住对方。
  现在标签控件**只占标签条那一行**，页面从它下方开始，两者零重叠；同时去掉嵌套子窗口，
  **页面控件全部扁平挂在主窗口上**（向导对话框一直这么做，稳定可见）。

## [v1.0.0] - 2026-09-17

首次发布。单文件 `SecureVault.exe`（Windows 10/11 64 位，`CGO_ENABLED=0`，无外部依赖，不写注册表）。

### Added

**交付形态**
- 纯 Go 原生 Win32 GUI（自研 `internal/ui` + `internal/ui/win` 两层封装），单文件 exe，约 7.7 MB。
- 支持 100% / 125% / 150% / 200% 屏幕缩放：进程声明 Per-Monitor V2，界面坐标统一走唯一的缩放点 `ui.L()`。
- 所有数据只写在 **exe 所在文件夹**的 `SecureVaultData\` 下（`keystore.json`、`vault.db`、`logs\`、`tmp\`）。

**启动与安全**
- 首次使用先设置主密码（≥8 位，两次确认），随后弹出恢复码，**只显示这一次**（可复制、可另存为 txt，关闭前二次确认）。
- 恢复码格式 `XXXX-XXXX-XXXX`（大写字母 + 数字，`crypto/rand` + 拒绝采样）；校验时忽略大小写、横线与空白。
- 忘记密码可用恢复码重置，并**轮换**出新恢复码（旧码立即失效）；密码与恢复码都丢失则数据无法解密。
- 打开程序默认不显示窗口，只驻留托盘；托盘标题只有 `SecureVault`。
- 关闭窗口 = 收进托盘 + **立即上锁**（停引擎、关数据库、清空内存密钥）；再次打开需输入密码；彻底退出必须走托盘「退出程序」并再次验证密码。
- 开机自启默认开启，用「开始菜单 → 启动」文件夹里的快捷方式实现（纯 Go 写 `.lnk`，可随时手动删除）。
- 连续 5 次密码错误锁定 60 秒，锁定状态持久化（重启依然生效）。

**三种模式与定时切换**
- 监控模式 / 复制模式 / 关闭，可随时手动切换。
- 定时切换：任意多条 `HH:MM - HH:MM → 模式`，支持跨午夜（如 `22:00 - 06:00`）与按星期生效；命中以计划为准，否则用手动模式。

**复制能力**
- 增量复制：只比较 `(大小, 修改时间)`，只拷新文件与改动过的文件。
- 目标文件夹命名遵循 **别名 > 卷标 > 型号 > 盘符**，并做 Windows 文件名净化（非法字符、保留设备名、超长截断）。
- 全程静默：不弹任何系统窗口，不调用 cmd / powershell / robocopy。
- 单文件失败自动重试（默认 2 次，间隔 200ms 递增）并继续，不中断整批；目标空间不足时安全停止。
- 纯 Go 实现，支持超过 260 字符的长路径、中文文件名与超长文件名。

**工具**
- 工具 1：把桌面（源目录可改）内容增量整理复制到指定位置，文件夹名固定为 `桌面`。
- 工具 2：设备别名，可覆盖界面显示名与复制文件夹名。

**设置**
- 开机自启开关、复制目标目录、日志保留 7/14/30 天、定时切换开关、记录设备移除事件开关。
- 修改密码（需已解锁）、重新生成恢复码（需当前密码 + 二次确认）。

**日志与监控记录**
- 纯文本日志：按天一个文件 `YYYY-MM-DD.txt`，UTF-8 + CRLF；默认自动删除 14 天以前（可改 7/30），支持手动清除 7 天前 / 清除全部。
- 监控记录：记录每次接入/移除的时间、盘符、总线类型、型号、厂商、VID、PID、USB 序列号、磁盘序列号、卷标、容量、剩余、文件系统、物理磁盘号、设备实例 ID、卷 GUID、设备路径、处理结果、复制文件数/字节数/耗时/目标目录。
- 支持按型号/卷标/VID/PID/序列号/盘符搜索 + 字段限定 + 事件类型 + 时间范围 + 分页浏览。
- 导出 CSV（UTF-8 BOM，Excel 打开中文不乱码）。
- 清除记录：7 天前 / 14 天前 / 30 天前 / 全部；**程序不会自动删除监控记录**。
- 点击任意一行可把该设备一键加入排除名单。

**排除名单**
- 设备排除规则 12 种属性（总线类型、VID、PID、USB 序列号、磁盘序列号、型号、卷标、文件系统、盘符、物理磁盘号、设备实例 ID、容量 `>=64GB` / `<=2GB` / `512MB`），规则之间是"或"。
- 排除 U 盘中的文件/文件夹名（支持 `*` 与 `?`，命中文件夹则整个子树跳过）、排除扩展名、只复制这些扩展名（白名单，留空 = 全部）。

**界面**
- 主面板 7 个标签页（状态 / 监控记录 / 排除名单 / 定时切换 / 工具 / 设置 / 日志）+ 3 格状态栏；`F5` 刷新、`Esc` 立即上锁。

**开发期开关（随构建存在，正式交付前会移除）**
- `-review`：写入演示数据后直接打开主面板，跳过密码流程，用于逐页评审排版与 DPI；若数据目录属于别的口令会自动重建，保证始终能打开。
- `-autotest`：自动验收，走真实流程（首次设置密码 → 解锁 → `afterUnlock` → 主面板 → 逐页切换 → 模拟设备接入 → 上锁 → 恢复码重置 → 改密校验），**29 项断言**，结果写入 `SecureVaultData\autotest.log`。

### Security

- 存储为加密 SQLite（`modernc.org/sqlite`，纯 Go）：设备序列号、卷标、型号、VID/PID、盘符、设备路径、备注、目标目录、名单、别名、增量标记路径等敏感文本字段一律 **AES-256-GCM 字段级加密**后以 BLOB 落盘（`nonce(12) ‖ ciphertext ‖ tag(16)`，固定 AAD）；时间、事件、容量等非敏感字段保留明文列以便排序过滤。
- 增量索引按 `HMAC-SHA256` 派生**盲索引**（`path_key`）做等值查询，既能按路径查找又不泄露路径明文。
- 密码/恢复码派生使用 **PBKDF2-HMAC-SHA256**（随机 16 字节 salt、200000 次迭代、派生 64 字节 = 32 字节 KEK + 32 字节 KMAC，纯标准库实现）。
- 主密钥（DEK，32 字节随机）用 **AES-256-GCM** 分别以密码派生密钥和恢复码派生密钥包裹；校验值用 `HMAC-SHA256(KMAC, 域分离标签)`，并以 `crypto/subtle.ConstantTimeCompare` 常量时间比较。
- `keystore.json` 只保存派生参数与密文，**绝不保存**密码、恢复码或 DEK 的明文；恢复码只在生成时返回一次。文件以 0600 权限原子写入。
- 连续失败 5 次冷却 60 秒，冷却状态持久化到磁盘。
- 上锁时清空内存密钥（`zero()` 擦除派生密钥与 DEK），并尽力触发 GC 缩短密钥驻留时间。
- 运行期不申请管理员权限（清单 `requestedExecutionLevel="asInvoker"`），不弹 UAC，不写注册表。
- 单元测试与端到端自检均包含"**磁盘上搜不到明文序列号/卷标**"的断言。

### Known limitations

- **无 C 编译器、无外网**：需求原文指定的 `lxn/walk` 必须 cgo + 联网才能编译，故 UI 改为自研纯 Go 原生 Win32 封装；代码不 import walk。
- **`go test -race` 不可用**：`-race` 强制要求 cgo，与 `CGO_ENABLED=0` 冲突；并发安全靠设计（互斥锁 / 单连接 / 串行化）与并发用例覆盖。
- **USB 真机分支未端到端验证**：开发机只有 NVMe 固定盘，没有可插拔 U 盘。VID/PID/USB 序列号解析、USBSTOR 兜底、设备父节点上溯等逻辑已用伪造设备实例 ID 与伪造系统广播做单测覆盖，**建议插一次真 U 盘复核**。
- **截图工具对深层子控件无效**：`WM_PRINT`/`PrintWindow` 不会递归绘制子窗口的子窗口，`scripts/shot` 抓主面板时只能看到标签条与背景；界面正确性改用 `scripts/winlist` 核对窗口树与几何尺寸。
- **复制目标不能位于源盘内部**：把 U 盘内容复制回该 U 盘自身会因增量索引导致行为不符合预期，界面未拦截该配置。
- **别名可以重名**：两个别名指向同一设备时，按数据库返回顺序取第一个。
- 只有已解锁（面板打开）时才监控与复制：开机自启仅驻留托盘；关闭窗口即上锁并停止引擎。
- 监控记录的关键词搜索在解密后于内存中完成，单次最多扫描并匹配最近的 20000 条候选。
- 结构变更没有 schema 迁移机制（建表使用 `CREATE TABLE IF NOT EXISTS`）：升级后新增的数据库列不会作用于已存在的 `vault.db`。
