# SecureVault —— U 盘自动复制与监控工具

> 一个 Windows 桌面小工具：插上 U 盘 / 移动硬盘后自动认出这块盘、记录它的全部信息，并按你的设置把盘内文件**增量复制**到指定目录。
> 单文件 exe、纯 Go 实现、`CGO_ENABLED=0`、无外部依赖进程、不写注册表，所有数据只落在 exe 自己旁边的 `SecureVaultData\` 里。
>
> **当前状态**：v1.0.5 —— 界面全部自绘直角扁平（白底 + 卡片 + 扁平标签条 + 自绘按钮/复选/单选/输入框 + 应用图标），
> 修复了"点托盘弹两个窗口""切换标签页残留""页面不能滚动""输入框压住按钮""界面比窗口大导致控件遮挡/显示不全"等问题，
> 并给每个页面的增删改清空加上了自动验收。编译 / 单元测试 / 端到端自检 / 自动验收（98 项）/
> 真实点击的界面验收（25 项）全部通过。详见 `CHANGELOG.md`。

## 1. 项目简介

**SecureVault 是一个 U 盘 / 移动硬盘自动复制与监控工具**：设备一插上，它就把这块盘的卷标、容量、文件系统、总线类型、型号、VID:PID、USB 序列号、磁盘序列号、物理磁盘号、设备实例 ID 等信息记录下来；如果当前是复制模式，再把盘内文件（可排除）**增量复制**到你指定的目录，文件夹自动按设备命名。

一句话核心价值：**插上盘就自动完成"认出它 + 备份它 + 留下可查的记录"，全程静默、离线可用、数据加密落盘。**

设计取向（需求原文：轻量、便利、安全）：

* **轻量**：单个 exe（约 7.5 MB），无安装程序、无服务、不调用 `cmd` / `powershell` / `robocopy`。
* **便利**：默认开机自启、启动即驻留托盘、插入设备无需任何操作。
* **安全**：面板一关就上锁（需再次输入密码才能打开面板）；彻底退出也要输密码；数据库里的敏感字段逐个加密存储。
  后台自动运行所需的密钥副本由 **Windows 用户凭据（DPAPI）**保护，只在本机本用户下可解，可在设置里一键关闭。

交付形态：

| 项目 | 现状 |
|---|---|
| 语言 / 运行时 | Go 1.24（`go.mod` 声明），后端与界面全部 Go |
| 可执行文件 | `dist\SecureVault.exe`，单文件，约 7.5 MB |
| cgo | 关闭（`CGO_ENABLED=0`） |
| 第三方依赖 | `golang.org/x/sys/windows`（Win32 调用）、`modernc.org/sqlite`（纯 Go SQLite 驱动），无第三方 UI 库 |
| 写注册表 | 从不 |
| 数据位置 | 仅 `<exe 所在目录>\SecureVaultData\` |
| DPI | 进程声明 Per-Monitor V2，全部坐标走 `ui.S()` 缩放（本机 144 DPI 实测正常） |

## 2. 重要说明：UI 技术选型

**这一节必须如实说明：最终交付的界面没有使用需求原文指定的 `github.com/lxn/walk`。**

* 需求原文要求：**"ui使用Lxn/walk的ui"**。
* 但 `lxn/walk` 必须 **cgo + C 编译器 + 联网拉依赖** 才能编译。
* 本机实测环境：**无外网**（`proxy.golang.org` / `github.com` / `goproxy.cn` 全部 TCP 超时）、**无 MSVC / MinGW / clang**、**模块缓存里没有 walk**。
* 因此按用户确认的**「方案 A」**，UI 改为**自研纯 Go 原生 Win32 封装**，分两层：
  * `internal/ui/win` —— Win32 API 最小封装层，直接绑 `user32` / `gdi32` / `kernel32` / `comctl32` / `shell32`（全部通过 `golang.org/x/sys/windows` 的 `NewLazySystemDLL` 动态调用），只做 DLL 绑定与常量声明，不含业务逻辑；
  * `internal/ui` —— 控件与窗体层：窗口、标签条、列表、按钮、编辑框、组合框、状态栏、卡片、画布自绘、DPI 缩放、托盘图标、模态对话框。
* 结果：`CGO_ENABLED=0`、单文件 exe、**零第三方 UI 依赖**，外观与行为就是 Windows 原生控件（公共控件 v6）。

**明确结论：**

* **代码里没有 `import "github.com/lxn/walk"`**（全仓库检索 0 命中），`go.mod` 里也不存在该依赖。
* 若要改回 `lxn/walk`，必须**先准备 C 编译器（MSVC 或 MinGW-w64）并打通网络**以拉取依赖，届时 `CGO_ENABLED=0` 与"纯离线构建"这两个前提都会失效。

## 3. 功能一览

> 以下逐条对齐需求原文，全部为已实现并验证的行为。

### 3.1 三种模式

| 模式 | 行为 |
|---|---|
| **监控模式** | 记录每一次设备接入 / 移除的完整信息，**不复制**任何文件 |
| **复制模式** | 记录设备信息，并把盘内文件（应用排除规则后）**增量复制**到指定目标目录 |
| **关闭** | 不监控、不复制：接入与移除都**不写监控记录**，只在文本日志里留一行"当前模式为「关闭」，不做任何处理" |

模式可随时手动切换（状态页单选 + "应用模式"），也可由定时计划接管。

### 3.2 定时切换

* 可添加**任意多条** `HH:MM - HH:MM → 模式` 的时间段，时间格式为 24 小时制 `HH:MM`（如 `22:00`），格式非法会提示。
* **支持跨午夜**：例如 `22:00 - 06:00`。
* 支持**按星期生效**：周一 ~ 周日 7 个复选框，默认全选（`Days` 位掩码，`0x7F` 表示每天）。
* 命中规则：**命中任一时间段时以计划为准，否则使用手动模式**；「启用定时切换」总开关可一键停用计划。
* 计划每 **20 秒**重算一次（跨午夜也能正确命中），界面状态栏每秒刷新。
* 每条计划可单独启用/停用、修改、删除，也可一键清空全部。

### 3.3 复制

| 能力 | 说明 |
|---|---|
| 增量复制 | 按 **(文件大小, 修改时间)** 判断是否变化，只复制新文件与改动过的文件，其余原样跳过 |
| 文件夹命名 | **别名 > 卷标 > 型号 > 盘符**，并做 Windows 文件名净化；重名/非法字符有兜底名 `Unknown` |
| 全程静默 | 复制 / 扫描 / 错误处理**不弹任何系统窗口**，不调用 `cmd` / `powershell` / `robocopy` |
| 失败不中断 | 单个文件失败按重试次数重试（默认重试 2 次，间隔递增），仍失败则跳过并继续整批 |
| 空间保护 | 复制前先算"待复制字节数 vs 目标剩余空间"，不足则**不开始**并返回明确错误；复制过程中每 **200 个文件**复查一次，不足则**安全停止**（已复制的文件保持有效） |
| 长路径 | 所有文件系统访问都用长路径包装，支持超过 260 字符的路径与文件名 |
| 默认参数 | 同名策略=覆盖、增量=开、复制后校验大小=开、保留修改时间=开、4 个并发工作协程、重试 2 次 |
| 启动补偿 | 程序启动时会先快照一次"已经插着的设备"，避免开机前就插好的盘被漏掉 |
| 并发保护 | 同一时刻只跑一个复制任务，多个盘同时接入不会互相抢带宽 |

### 3.4 密码 / 恢复码 / 上锁

* 首次打开先设密码：**至少 8 位**（按字符数计，中文不会被截断），**两次确认**。
* 设完立刻弹出**恢复码**，格式 `XXXX-XXXX-XXXX`（大写字母 + 数字，`crypto/rand` + 拒绝采样），**只显示这一次**；关闭前会二次确认，支持"复制恢复码"与"另存为 txt"。
* 忘记密码：解锁窗口有「忘记密码 / 用恢复码重置」按钮，用恢复码重置密码，并**轮换出新恢复码**（旧码立即失效）。
* 恢复码比较**忽略大小写与横线**，并使用常量时间比较。
* **连续 5 次密码错误 → 锁定 60 秒**，锁定状态持久化，重启程序依然生效。
* 修改密码需输入当前密码，**恢复码保持不变**；「重新生成恢复码」需当前密码 + 二次确认。
* 程序启动行为（**按实机验收要求设定**）：
  * **已设过主密码**：双击启动后**只驻留托盘、不显示任何窗口**，左键单击托盘图标才打开面板；
    同时会**在后台自动恢复监控与复制**（见下一条），面板始终是锁着的；
  * **从未设过主密码**：弹出「SecureVault · 首次设置」窗口要求设置密码；关掉这个窗口会问「尚未设置密码，确定退出吗？」，确认即退出；
  * 开机自启用的 `-silent`、以及非交互会话：同样只驻留托盘、不弹任何窗口。
* **关闭面板窗口 = 收进托盘 + 立即上锁**（面板需重新输密码才能打开），**后台监控与复制继续运行** ——
  这是"插上 U 盘自动复制"能成立的前提：程序是后台工具，不能只在面板开着的时候才工作。
* **后台自动运行**（设置页「关闭面板后继续在后台监控与复制」，默认开启）：
  * 开启时：面板关闭后引擎继续监控设备；**开机自启/重启后也不需要输密码即可自动恢复监控与复制**。
    为此密钥库里会保存一份由 **Windows 用户凭据（DPAPI）**保护的 DEK 副本（`keystore.json` 里的 `autoUnlock` 字段，
    只在本机本用户下可解，拷到别的机器/别的账户都解不开）；密码与恢复码仍然不落盘。
  * 关闭时：关闭面板即停引擎、关数据库、清空内存密钥（旧行为，最严格）；
    重启程序后必须先打开面板输入密码才会开始监控。
  * 无论哪种设置，**打开面板 / 退出程序 / 改密码 / 看恢复码都必须输入密码**。
* 彻底退出走托盘「退出程序」：**未设置过密码时直接退出**（首次使用想放弃不必先设密码）；已设置过密码时需验证身份。
* 托盘图标创建失败（例如开机自启时 Explorer 还没准备好）**不会退出程序**：会在后台自动重试，日志里记录。
  这时也可以用"再运行一次 exe"来打开面板（第二个进程会激活已有实例后退出）。

### 3.5 托盘

* 托盘标题**只有 `SecureVault` 一个**，不附加任何状态后缀。
* **左键单击 = 打开面板（需要输入密码）；右键菜单只有「退出」一项**（按实机验收要求精简，避免菜单里塞满不常用的项）。
* 同一时刻只有一个主面板：重复单击托盘不会叠出第二个窗口。
* 上锁仍然随时可用：关闭面板（×）、面板内按 `Esc`、最小化窗口（设置里开启「最小化时收进托盘」时）、或设置页的「立即上锁」。
* Explorer 崩溃重启后程序会自动重新添加托盘图标（监听 `TaskbarCreated` 消息）。
* 托盘图标暂时创建失败时程序照常运行并自动重试；也可以"再运行一次 exe"让已有实例弹出解锁窗口。
* 非交互会话（没有 WinSta0 桌面，例如某些服务/计划任务环境）下只驻留托盘，不弹任何窗口。

### 3.6 开机自启

* 默认**开启**，用「开始菜单 → 启动」文件夹里的快捷方式实现，**不写注册表**，可随时手动删除。
* 快捷方式名为 `SecureVault.lnk`，指向 exe 并带 `-silent` 参数。
* 可在设置页随时开关；设置里开着但 `.lnk` 被删掉时，程序会在日志里提示。

### 3.7 工具 1：桌面整理

* 把源目录（默认当前用户**桌面**，含 OneDrive 重定向的桌面；可改成任意目录）里的全部内容**增量复制**到目标目录下的 **`桌面`** 文件夹。
* 目标目录可"使用与 U 盘复制相同的目标目录"（默认），也可单独指定。
* 整理复制在后台线程执行，过程中按钮会禁用，完成后在页面上显示结果（复制 / 跳过 / 失败数、总字节数、耗时）并写入日志；全程静默，不会弹出任何系统窗口。

### 3.8 工具 2：设备别名

* 支持 7 种匹配属性：**卷标、设备型号、USB 厂商 ID、USB 产品 ID、USB 序列号、磁盘序列号、设备实例 ID**。
* 别名会**覆盖界面显示名与复制文件夹名**（修改别名后，下次复制写入新文件夹名，旧文件夹保留）。
* 支持添加 / 保存修改 / 删除选中；列表右键可「用本机磁盘填充匹配值…」「复制匹配值」。

### 3.9 监控记录

* 记录每一次**接入 / 移除**，字段包括：时间、盘符、总线类型、型号、厂商、VID、PID、USB 序列号、磁盘序列号、卷标、容量、剩余容量、文件系统、物理磁盘号、设备实例 ID、卷 GUID、设备路径、是否可移动、处理结果、复制文件数 / 字节数 / 耗时 / 目标目录、备注。
* 搜索：关键词 + **字段限定**（全部字段 / 设备型号 / 卷标 / VID / PID / 序列号 / 盘符）+ **事件类型**（全部 / 接入 / 移除）+ **时间范围**（全部时间 / 最近 24 小时 / 最近 7 天 / 最近 30 天），支持重置。
* 分页浏览：每页 100 条，上一页 / 下一页，可查看单条详情。
* **导出 CSV**：UTF-8 BOM（Excel 打开中文不乱码），25 列，一次最多导出 2 万条，文件名形如 `SecureVault-监控记录-20260917-003000.csv`。
* 清除记录：**7 天前 / 14 天前 / 30 天前 / 全部**，均需确认，不可撤销。
* **程序不会自动删除监控记录**，只有你手动清除才会消失。
* 列表右键菜单：「加入排除名单（不再复制此设备）」「查看详情」「复制序列号」「复制整行」，页面上也有「加入排除名单」按钮。

### 3.10 排除规则

**设备排除规则（12 种属性，规则之间是"或"，命中任意一条即只记录、不复制）：**

| # | 属性 | 匹配方式 |
|---|---|---|
| 1 | 总线类型 | 忽略大小写相等（如 `USB`、`NVMe`、`SATA`） |
| 2 | USB 厂商 ID | 等于 VID，或等于 `VID:PID` 组合 |
| 3 | USB 产品 ID | 忽略大小写相等 |
| 4 | USB 序列号 | 忽略大小写相等 |
| 5 | 磁盘序列号 | 忽略大小写相等 |
| 6 | 设备型号 | 相等，或通配符 `*` `?` 匹配 |
| 7 | 卷标 | 相等，或通配符 `*` `?` 匹配 |
| 8 | 文件系统 | 忽略大小写相等（`NTFS` / `exFAT` / `FAT32`） |
| 9 | 盘符 | 带不带冒号都行（`E` 或 `E:`） |
| 10 | 物理磁盘号 | 与数字相等 |
| 11 | 设备实例 ID | 相等，或包含子串 |
| 12 | 容量 | 表达式：`512MB`（精确，带 ±2% 容差）、`=512MB`、`>=64GB`、`>64GB`、`<=2GB`、`<2GB`，支持 MB / GB / TB |

**文件 / 文件夹名与扩展名名单（排除名单页）：**

| 名单类型 | 含义 |
|---|---|
| 排除文件/文件夹名 | 支持通配符 `*` 与 `?`（如 `*.tmp`、`node_modules`） |
| 排除扩展名 | 如 `.log`、`.mp4`（自动规范化，带不带点都行） |
| 只复制这些扩展名 | **留空表示全部复制**；一旦填写则只复制这些扩展名 |

设备排除规则还支持「从本机磁盘快速添加…」（直接从当前枚举到的磁盘里挑属性值）与「清空规则」。

### 3.11 日志

* 纯文本 `txt`，**按天一个文件**：`<数据目录>\logs\yyyy-mm-dd.txt`，UTF-8 编码、行尾 CRLF。
* 行格式：`2006-01-02 15:04:05.000 [级别] 内容`（级别：DEBUG / INFO / WARN / ERROR）。
* 默认自动删除 **14 天以前**的日志，可在设置里改为 **7 / 30 天**；启动与改设置时都会自动清理一次。
* 支持手动**清除 7 天前**与**清除全部日志**。
* 日志页可列出所有日志文件（日期 / 大小 / 文件）、预览内容（默认末尾 300 行）、一键打开日志文件夹。
* 磁盘写满 / 写失败不会让程序崩溃。

### 3.12 设置项

| 设置 | 说明 |
|---|---|
| U 盘复制目标根目录 | 可手输或「选择…」；不存在时会询问是否创建 |
| 开机自动启动 | 在「开始菜单 → 启动」里创建/删除快捷方式 |
| 日志保留天数 | 7 天 / 14 天（默认）/ 30 天 |
| 启用定时切换 | 总开关 |
| 记录设备移除事件 | 关闭后只记接入 |
| 最小化时收进托盘 | 默认开启：最小化窗口 = 收进托盘 + 上锁 |
| 关闭面板后继续在后台监控与复制 | 默认开启（推荐）。开启时关掉面板仍会自动复制、重启后无需输密码即可自动恢复；关闭后关闭面板即停引擎、清空内存密钥，重启后必须先手动解锁 |
| 修改密码 | 需当前密码 |
| 重新生成恢复码 | 需当前密码 + 二次确认，旧码立即失效 |
| 立即上锁 | 一键上锁 |
| 数据位置 | 显示程序目录 / 数据目录 / 日志目录 / 数据库 / 密钥库 / 自启快捷方式路径与状态 |

## 4. 快速开始

1. **放置 exe**：把 `SecureVault.exe` 放到一个**有写权限**的目录。常见选择：
   * U 盘根目录（随身携带，插到哪台机器都能用）；
   * 桌面；
   * 自己新建的文件夹（如 `D:\Tools\SecureVault\`）。
   > 提示：程序的数据目录固定是 **exe 所在目录**下的 `SecureVaultData\`。把 exe 放在 U 盘上时，数据也在这块 U 盘上——**运行中不要拔掉它**。
   > 另外请勿把"复制目标目录"设置成源盘内部的路径（见 [已知限制](#12-已知限制) L4）。
2. **双击运行**。首次启动会弹出「**SecureVault · 首次设置**」窗口，要求设置主密码：**至少 8 位**，输入两次。
3. **抄下恢复码**。设置完成后立刻弹出「**SecureVault · 恢复码（只显示这一次）**」，格式 `XXXX-XXXX-XXXX`。
   * 点「复制恢复码」或「另存为 txt」保存好，再点「我已保存，继续」。
   * **这个码只显示这一次**，忘记密码时只能靠它重置；密码和恢复码都丢了，数据将永久无法解密。
4. **打开面板配置目标**。解锁后进入主面板 → 「**设置**」标签页 → 在「U 盘复制目标根目录」里选择（或输入）目标目录 → 点「**保存设置**」。
5. **切到复制模式**。回到「**状态**」标签页 → 选「复制模式（插入设备后自动增量复制）」→ 点「**应用模式**」。
   > 若还没设目标目录就切复制模式，程序会提示你先去设置页设置。
6. **插上 U 盘 / 移动硬盘**，剩下的自动完成：记录写入监控记录、文件增量复制到 `<目标目录>\<设备名>\`。托盘图标一直在，随时可右键查看或上锁。

7. **关掉面板也没关系**。默认设置下把窗口关掉只是"收进托盘 + 上锁"：**后台的监控与复制照常进行**，要再看界面才需要输密码。

以后每次启动：程序**只驻留托盘、不显示窗口、并自动在后台恢复监控与复制**（不需要输密码）；打开面板用**左键单击托盘图标**（或再次双击 exe——第二个进程会自动激活已有实例后退出），此时才需要输入密码。

## 6. 数据与安全

### 6.1 数据位置

所有数据只在 **`<exe 所在目录>\SecureVaultData\`**：

| 路径 | 内容 |
|---|---|
| `SecureVaultData\vault.db` | 加密 SQLite 数据库（监控记录、排除规则、名单、别名、定时计划、设置、增量索引） |
| `SecureVaultData\vault.db-wal` / `vault.db-shm` | SQLite WAL 模式下运行时出现的辅助文件（正常现象） |
| `SecureVaultData\keystore.json` | 密钥库：KDF 参数、被包裹的 DEK、校验值、失败计数与锁定时间；可选一段由 Windows 用户凭据（DPAPI）保护的 DEK 副本（`autoUnlock`，用于开机自启后台自动运行，权限 `0600`，原子写） |
| `SecureVaultData\logs\` | 按天的纯文本日志 |
| `SecureVaultData\tmp\` | 原子写用的临时文件 |

* **绝不写 C 盘其它位置、不写注册表**（已用实际运行验证：只生成上述文件）。
* 目录创建后还会**真实写一个小文件做可写性探测**，比只看权限位可靠。
* 设置在数据库里，不使用独立配置文件（避免"两份真相"）。

### 6.2 密钥体系

```
密码 ──┐                                    ┌── pwdWrap  (AES-256-GCM) ──┐
       ├─ PBKDF2-HMAC-SHA256(200000 次, 16B salt) ─→ KEK(32B) + KMAC(32B)│
恢复码 ─┘                                                              ├─→ 同一把随机 DEK(32B)
                                          └── recWrap  (AES-256-GCM) ──┘
```

* KDF：**PBKDF2-HMAC-SHA256**，随机 16 字节 salt，**200000 次**迭代（纯标准库实现，附权威测试向量回归）。
* 每次派生 64 字节：前 32 字节作 KEK（包裹 DEK），后 32 字节作校验密钥（HMAC 校验），不存明文或明文的简单哈希。
* 包裹：**AES-256-GCM**，随机 12 字节 nonce，附加数据分别固定为 `SecureVault|keystore|v1|pwd` 与 `SecureVault|keystore|v1|rec`。
* **密码与恢复码各自独立包裹同一把 DEK**，所以改密码不影响恢复码；重置（用恢复码）会轮换出新恢复码。
* 恢复码明文**绝不落盘**，只在生成时返回一次。

### 6.3 数据库加密

* 驱动：`modernc.org/sqlite`（**纯 Go**，`CGO_ENABLED=0` 可用），DSN 启用 `journal_mode(WAL)`、`busy_timeout(5000)`、`foreign_keys(1)`、`synchronous(NORMAL)`。
* **敏感字段逐字段 AES-256-GCM 加密后以 BLOB 存储**，密文布局 `nonce(12) || ciphertext || tag(16)`，附加数据固定为 `SecureVault|field|v1`；空串直接存 `NULL`。
* 加密列（均为 BLOB）：备注、目标目录、盘符、**卷标**、总线类型、**型号**、厂商、**VID**、**PID**、**USB 序列号**、**磁盘序列号**、文件系统、**设备实例 ID**、卷 GUID、设备路径；名单的值与备注；别名的匹配字段/值/别名/备注；定时计划备注；设置项；增量索引的路径键 / 源路径 / 目标路径。
* 只有时间、事件类型、动作、容量等非敏感字段保留明文列，用于 SQL 排序与过滤。
* 关键词搜索的做法：SQL 只做时间 / 事件硬过滤并加 `LIMIT 20000` 行保护，**解密后在 Go 侧**做关键词过滤与分页（记录量级不大，每次插拔一行）。
* 单元测试里有一条硬断言：**直接读数据库文件字节，搜不到明文序列号**（端到端自检里同样检查卷标与序列号）。

### 6.4 上锁语义

上锁 = 销毁主面板（窗口从屏幕上消失、进程留在托盘） + 之后打开面板必须重新输入密码。

* **默认（设置页「关闭面板后继续在后台监控与复制」开启）**：引擎与数据库继续运行，插拔设备照常记录与复制；
  密钥库里保存一份由 Windows 用户凭据（DPAPI）保护的 DEK 副本，供开机自启后台自动恢复使用。
* **关闭该设置**：上锁 = 停引擎 → 关数据库句柄 → 清空内存密钥 → 触发 GC（最严格，但重启后必须先手动解锁才会监控）。
* 触发方式：关闭面板（×）、最小化窗口（设置里「最小化时收进托盘」开启时）、设置页「立即上锁」、面板内按 `Esc`。
* 无论哪种模式：改密码、重新生成恢复码、彻底退出，都必须再次输入密码。

### 6.5 单实例

用命名互斥体 `Local\SecureVault_SingleInstance_8F3A21` 保证只有一个实例；重复启动时，新进程会广播消息**激活已有实例**并以退出码 0 结束（不会出现两个托盘图标）。

## 7. 开机自启

* 实现方式：在**「开始菜单 → 启动」文件夹**（`SHGetKnownFolderPath(FOLDERID_Startup)`，失败时回退到 `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`）里创建快捷方式 **`SecureVault.lnk`**，指向 exe 并带参数 **`-silent`**。
* `.lnk` 是**纯 Go 直接写 Shell Link 二进制格式**（不使用 COM，也不调用任何外部程序）；写入采用"先写 .tmp 再改名"的原子方式。
* **不写注册表 Run 项**——你随时可以直接删掉这个 `.lnk` 文件来关闭自启，也可以在设置页取消勾选「开机自动启动」由程序删除。
* 默认开启；程序每次解锁后会以"快捷方式是否真实存在"为准同步一次状态。

## 9. 从源码构建（离线）

本机无外网，依赖全部来自本机已有的模块缓存（只读复用）。在仓库根目录执行（**PowerShell**）：

```powershell
$env:Path="C:\Program Files\Go\bin;$env:Path"
cd D:\DeepSeek-Harness\project\auto-cy-file-2
$env:GOPATH="$PWD\.gopath"; $env:GOMODCACHE="D:\DeepSeek-Harness\project\auto-cy-file\.gomodcache"
$env:GOCACHE="$PWD\.gocache"; $env:GOTMPDIR="$PWD\.gotmp"
$env:GOFLAGS="-mod=mod"; $env:GOSUMDB="off"; $env:CGO_ENABLED="0"; $env:GOPROXY="off"
go build -ldflags="-s -w -H=windowsgui" -trimpath -o .gotmp\sv-raw.exe .\cmd\securevault
go run .\scripts\addmanifest .gotmp\sv-raw.exe dist\SecureVault.exe assets\securevault.manifest
```

说明：

* `CGO_ENABLED=0` + `GOPROXY=off`：完全离线、纯 Go 构建。
* `-H=windowsgui`：生成 GUI 子系统程序（双击不弹黑色控制台窗口）；`-s -w` 去掉符号与调试信息；`-trimpath` 去掉本地路径。
* 这条命令序列本次已实测通过（退出码均为 0）：注入清单 + 应用图标后的交付文件为 **7,969,280 字节**（约 7.6 MB；图标与源码不同会让字节数有小幅差异）。
* 第 4 个参数是可选的图标文件；不传就只注入清单（此时 exe 没有自己的图标）。
* 若 `dist` 目录不存在，请先创建：`New-Item -ItemType Directory -Force dist`（`addmanifest` 不会自动建目录）。
* 也可以点源加载脚本：`. .\scripts\dev.ps1`（只设置环境变量）或 `.\scripts\dev.ps1 build`（构建到 `dist\SecureVault.exe`）。注意 `dev.ps1` 里的 `Invoke-SVBuild` 只加了 `-s -w`，**不含 `-H=windowsgui`**，要交付"无控制台"的 exe 请用上面的显式命令。

### 为什么必须有 `scripts/addmanifest` 这一步

`go build` 生成的裸 exe **没有应用程序清单**，会带来三个真实问题：

1. **comctl32 v6**：不申请 6.0 版本，进程会加载**老版公共控件（5.x）**，此时列表控件只认 ANSI 消息——发送 `LVM_INSERTCOLUMNW` 之类的宽字符消息会无法识别，**界面直接卡死**。
2. **Per-Monitor V2 高 DPI 感知**：不声明的话，在 125% / 150% / 200% 缩放下界面会模糊、错位。
3. **longPathAware**：不声明则超长路径（>260 字符）行为不一致。

清单文件是 `assets\securevault.manifest`（还包含 `asInvoker` 普通权限、Win7~Win11 的 `supportedOS`、UTF-8 `activeCodePage`）。

因为**本机没有 `rc.exe` / `windres`**，无法用常规方式编译资源，所以 `scripts/addmanifest` 用**纯 Go 直接构造 PE 的 `.rsrc` 段**：追加一个名为 `.rsrc` 的节，写入 `RT_MANIFEST(24)` / ID `1` / LANG `1033` 的清单资源，并更新 `OptionalHeader` 的 `DataDirectory[RESOURCE]` 与 `SizeOfImage`；已存在 `.rsrc` 段时会跳过，避免重复注入。

> 该工具**只注入清单资源**，不注入图标资源；托盘与界面图标来自程序内嵌的图标文件（`internal/app/assets/securevault.ico`，通过 `//go:embed all:assets` 打包）。
> 项目里的图标本身也是纯 Go 生成的：`go run .\scripts\genicon`。

## 13. 常见问题

**Q1：忘记密码了怎么办？**
在解锁窗口点「**忘记密码 / 用恢复码重置**」，输入恢复码 + 新密码（≥8 位，两次确认）。重置成功后程序会**轮换出新的恢复码**（旧码立即失效），新恢复码同样只显示一次。

**Q2：恢复码也丢了怎么办？**
**没有办法。** 密码与恢复码各自独立包裹同一把数据密钥，两者都丢失时数据无法解密——程序里没有后门，也无法帮你找回。此时只能删除 `SecureVaultData\keystore.json` 重新初始化（**原有数据将永久无法解密**，程序在密钥库损坏时也会这样提示）。

**Q3：托盘图标不见了怎么办？**
先看托盘是否把图标折叠进了"隐藏的图标"区域（点托盘的小三角展开，可以把 SecureVault 拖到常驻区）。如果确实丢了：程序监听了 Explorer 的重启消息（`TaskbarCreated`），**Explorer 崩溃重启后会自动重新添加图标**；万一图标创建失败（例如开机自启时 Explorer 还没准备好），程序**不会退出**，会在后台每秒重试并在日志里记录。
此时也能打开面板：**再双击一次 exe**，第二个进程会把已有实例唤醒并弹出解锁窗口（第二个进程自己直接退出，不会出现两份程序）。

**Q4：程序放在只读目录（如只读 U 盘、无写权限的目录）会怎样？**
启动时数据目录初始化会失败：程序**立即报错退出（退出码 3）**，不会进入正常运行，也不会初始化密钥库或数据库。由于交付版是无控制台的 GUI 程序，你通常看不到弹窗，只会发现"双击没反应"——请把 exe 换到有写权限的目录（桌面、自建文件夹、可写 U 盘等）。日志目录不可写同样是退出码 3；`keystore.json` 无法读取则是退出码 4（这一种会弹窗提示）。

**Q5：监控记录为什么不会自动删？**
这是**设计如此**：需求明确要求"监控记录只会在你手动清除时删除，程序不会自动删"。要清理请在「监控记录」页点「清除记录…」，选择 **7 天前 / 14 天前 / 30 天前 / 全部**（均需确认，不可撤销）。注意**日志**与监控记录是两套策略：日志默认自动删除 14 天前的文件（可在设置里改为 7 / 30 天），而监控记录永不自动删除。

**Q6：插上盘后什么都没发生？**
依次检查：① 当前模式是不是「关闭」或「监控模式」（监控模式只记录、不复制）；② 设置页是否已填「U 盘复制目标根目录」；③ 该设备是否命中了排除规则（监控记录里会显示"已排除"并写明命中了哪条规则）；④ 目标盘剩余空间是否足够（不足时不会开始复制，日志里有明确说明）；⑤ 设置页的「关闭面板后继续在后台监控与复制」是不是被关掉了（关掉后必须保持面板打开才会监控）；⑥ 看一下日志（「日志」页）——每次插拔、每次复制都会写一行。

**Q6b：关掉面板之后，程序还在工作吗？**
在。默认设置下，关闭面板只是把界面收进托盘并上锁（要再打开必须输密码），**后台的监控与复制照常运行**；开机自启后也会自动恢复后台运行。如果希望"关闭面板就不工作"，在设置页取消「关闭面板后继续在后台监控与复制」即可。

**Q7：能不能不用开机自启？**
可以。设置页取消勾选「开机自动启动」并保存即可；也可以直接删除「开始菜单 → 启动」文件夹里的 `SecureVault.lnk`（程序从不写注册表，删掉即彻底关闭）。

**Q8：程序联网吗？会上传数据吗？**
不会。程序没有任何网络功能；复制时不调用 `cmd` / `powershell` / `robocopy`；所有数据只写在 exe 旁边的 `SecureVaultData\` 目录里。

**Q9：怎么确认我的数据真的加密了？**
可以自己验证：`go run .\scripts\smoke` 会做一次"磁盘上搜不到明文序列号与卷标"的检查；单元测试 `internal/store/store_test.go` 里也有同样性质的断言。你也可以用文本/十六进制工具搜索 `SecureVaultData\vault.db`，卷标、序列号、型号、路径等都搜不到（它们是 BLOB 密文）。
