# SecureVault 使用手册（v2.0 Python 版）

本手册按「第一次用 → 日常使用 → 排查问题」的顺序写，照着做就能上手。

---

## 一、第一次使用

1. **放好程序**
   把 `SecureVault.exe` 放在一个你有写权限的目录（例如 `D:\SecureVault\`）。
   程序会在同一目录下建 `SecureVaultData\` 存放全部数据；
   **不要**放在只读目录里，也不要一边用一边把整个文件夹移走。

2. **双击启动**
   第一次会出现一个**老式小弹窗「首次使用」**（约 420×290，不是整个屏幕）：
   里面有「主密码」「确认密码」两个凹入输入框、「显示密码」勾选框和「确定」按钮。

   > 解锁与首次设置都是**独立的小弹窗**（原生控件、老一点的样式，不是 Win95 那种），
   > 而且**解锁之前界面上不会出现软件名**（窗口标题也只写「解锁」/「首次使用」）。
   > 弹窗会出现在**屏幕中央**。
   > 所有密码/恢复码输入框都有「显示密码」勾选框，忘了打到哪一位可以勾上看一眼。

   > **忘记密码**：解锁窗口里**默认看不到**「忘记密码」按钮。
   > 在**密码框为空**的时候，**10 秒内连点「确定」6 次**，它才会临时出现，
   > **10 秒后自动消失**（超过 10 秒会重新计数）。界面上不会有任何提示告诉你这个操作。
   > 托盘「退出程序」的密码框、以及清除记录 / 清除日志的确认框也有同样的入口：
   > 点开「忘记密码」后走恢复码重置流程，重置成功后**继续原来的操作**（退出 / 清除）。
   > 首次设置密码时，窗口里会提示"恢复码可以找回密码"。

   > **密码错误提示**（一共 5 次机会，用完封禁 5 分钟）：
   > 第 1、2 次只显示"密码错误"；第 3 次会告诉你还剩几次；
   > 剩 2 次和剩 1 次时会同时提示再错就封禁 5 分钟。

   - 密码**至少 8 位**，两次必须一致；
   - 点「设置密码并继续」后，会弹出**只显示一次**的恢复码，格式 `XXXX-XXXX-XXXX`。

3. **保存恢复码（很重要）**
   弹窗里有三个操作：

   | 按钮 | 作用 |
   |---|---|
   | 复制恢复码 | 复制到剪贴板（建议立刻粘到记事本里） |
   | 另存为 txt… | 存成一个文本文件，建议存到 U 盘或网盘 |
   | 我已保存恢复码 | 确认保存后关闭窗口 |

   > 忘记密码时**只能**用恢复码重置。恢复码也丢了，数据就再也解不开了——这是设计如此。
   > 如果当时没保存，可以在「设置 → 重新生成恢复码」里重新生成一个（旧码立即失效），
   > 但这一步需要输入当前密码。

4. **设置复制目标**
   打开「设置」页 → 「U 盘复制目标根目录」→ 点「选择…」选一个目录（例如 `D:\Backup`）
   →「保存设置」。复制模式必须有这个目录，否则设备接入时只会记录一条「未设置复制目标目录」。

5. **选模式**
   「状态」页 → 点「复制模式」→ 点「应用模式」。此时插上 U 盘就会自动增量复制。

## 二、界面总览

窗口从上到下是：**标题条 → 七个标签页 → 状态栏**。

- 标题条右侧：「立即上锁」「刷新当前页」。
- **点标题条上的版本号（v2.1.0）** 会用浏览器打开项目主页
  <https://github.com/816633/securevault>。
- 状态栏三段：① 当前模式（含「定时生效中」「正在复制…」「最近事件」）
  ② 复制目标 ③ 待机 / 正在复制 / 上次复制时间。
- **状态栏上面是提示条**：所有操作结果（保存成功、已添加、校验失败、复制完成…）
  都显示在这里，按级别显示灰 / 绿 / 橙 / 红；普通提示 6 秒后自动消失，
  警告与错误会一直留到下一次操作。卡片里只保留固定说明文字。
- 七个标签：状态、监控记录、排除名单、定时切换、工具、设置、日志。
- **表格都是多选的**：每行左边有复选框（点一下勾选），也可以直接用鼠标拖拽划选、
  按 Ctrl / Shift 多选；点复选框那一列的表头可以全选 / 全不选。
- **每个表格都能右键**：弹出的菜单按栏目不同而不同（记录页是加排除/详情/复制，
  当前设备是看参数/复制序列号/打开，规则与名单是复制/删除，计划是载入/启停/删除，
  别名是载入/复制/删除，日志是打开/复制路径/复制内容）。
- **主页「当前设备」双击**就能看到这台设备的全部参数。
- **按钮有主次**：蓝色是主操作、红色是删除类危险操作、灰色是次要操作。
  每一次点击的结果都会显示在底部提示条里。
- 打开面板会**直接显示上次停留的页面**（第一次是「状态」），不需要先点一下顶栏。
- 窗口拉小、屏幕矮时，页面会自动出现细滚动条；鼠标滚轮即可上下滚。
- 拉大缩小 / 最大化窗口时内容会立刻重排，不会出现空白或"还没加载"的样子。
- 快捷键：`Esc` = 立即上锁；`F5` = 刷新当前页。

## 三、逐页说明

### 1）状态

- **运行模式**：三个按钮（复制模式 / 监控模式 / 关闭）中选一个，再点「应用模式」。
  被选中的按钮会变成蓝色实心。
- **运行状态**：生效模式、手动模式、复制目标、定时计划是否启用、下次切换还有多久、
  最近事件、上次复制统计、各类规则与记录条数。
- **当前设备**：点「刷新设备列表」，列出本机所有硬盘与 U 盘的
  盘符 / 卷标 / 总容量 / 剩余 / 文件系统 / 总线 / 型号 / VID:PID / 序列号。
  插上 U 盘后点一次刷新就能看到它被识别成什么。

### 2）监控记录

- 上方是查询条件：**关键词**（配合下面的「字段」下拉可以只搜某个字段）、
  **事件**（全部 / 接入 / 移除）、**时间**（全部 / 最近 24 小时 / 7 天 / 30 天）。
  点「查询」开始，点「重置」清空条件。
- 中间是列表，每页 100 条，「上一页 / 下一页」翻页。
- 双击一行看**详情**（二十多个字段，含设备路径与卷 GUID）。
- 右键菜单：加入排除名单 / 查看详情 / 复制序列号 / 复制整行。
- 按钮：

  | 按钮 | 说明 |
  |---|---|
  | 查看详情 | 同上 |
  | 加入排除名单 | 按「磁盘序列号 → USB 序列号 → 卷标 → 盘符」的优先级自动选一个属性加规则 |
  | 导出 CSV… | 导出当前时间范围内的记录（UTF-8 BOM，Excel 打开中文不乱码） |
  | 清除记录… | 选 7 / 14 / 30 天前或全部，**需要二次确认**；程序本身不会自动删记录 |

### 3）排除名单

**设备排除规则**（命中任意一条 = 只记录、不复制）：

> 列表里**第一条是系统内置规则「内置硬盘」**：默认启用，把本机内置硬盘（C:、D: 等固定磁盘）
> 排除掉，只记录不复制。**这条规则不能删除**（点删除会被拒绝）。
> 需要修改时点「内置硬盘规则…」：程序会先警告"解锁后内置硬盘也会被复制、可能会报错、
> 不建议解锁"，再要求**输入密码**；解锁后可以随时点同一个按钮**恢复默认**（同样要密码）。

1. 「属性」下拉选一种：总线类型 / USB 厂商 ID / USB 产品 ID / USB 序列号 /
   磁盘序列号 / 设备型号 / 卷标 / 文件系统 / 盘符 / 物理磁盘号 / 设备实例 ID / 容量。
2. 填「匹配值」：
   - 型号与卷标支持通配符：`SanDisk*`、`*备份*`；
   - 盘符写 `E` 或 `E:` 都行；
   - 容量支持 `512MB`（±2% 容差）、`=512MB`、`>=64GB`、`>64GB`、`<=2GB`、`<2GB`。
3. 点「添加规则」。下方列表里可以「删除选中」「清空规则」。
4. 不想手填？点「**从本机磁盘快速添加…**」，在弹出的列表里直接点某个属性值就能加规则
   （比如某块盘的磁盘序列号）。

**文件 / 文件夹名单**：

| 类型 | 说明 |
|---|---|
| 排除的文件/文件夹名 | 支持 `*` `?`，命中文件夹则整个子树跳过（如 `node_modules`、`*.tmp`） |
| 排除的扩展名 | 如 `.log`、`.mp4`，带不带点都行 |
| 只复制这些扩展名 | **留空表示全部复制**；一旦填写就只复制这些扩展名 |

### 4）定时切换

1. 填「起始」「结束」（`22:00` / `06:00`；写成 `8:00` 会自动补成 `08:00`）。
2. 选「模式」（复制模式 / 监控模式 / 关闭）。
3. 勾「生效日」（默认全勾）和「启用」。
4. 点「添加计划」。下方列表会显示，点一行可以载入到表单里改，再点「保存修改」。
5. 列表上方的「启用定时切换」是总开关；「清空全部」删除所有计划。
6. 页面底部会显示「当前生效模式 + 下次切换还有多久」。

> 命中规则：命中任一时间段就以计划为准，否则用手动模式。跨午夜（22:00 - 06:00）按段判断。

### 5）工具

**工具 1 · 桌面整理复制**

- 「源目录」默认是你的桌面（兼容 OneDrive 重定向），可改成任意目录。
- 「目标目录」可以单独指定，也可以勾「使用与 U 盘复制相同的目标目录」。
- 点「开始整理复制」，内容会增量复制到目标目录下的 `桌面` 文件夹；
  复制在后台进行，页面下方会显示结果（复制/跳过/失败数、总字节、耗时）。

**工具 2 · 设备别名**

- 选「匹配属性」（卷标 / 型号 / VID / PID / USB 序列号 / 磁盘序列号 / 设备实例 ID）
  → 填「匹配值」→ 填「别名」→ 点「添加别名」。
- 别名会覆盖界面显示名与**复制出的文件夹名**。具体规则：
  * 新建别名：`<原名>` → **`<原名>_<别名>`**
  * 修改别名：`<原名>_<旧别名>` → **`<原名>_<新别名>`**
  * 删除别名：`<原名>_<别名>` → **`<原名>`**
  改名是直接改目录名（里面的文件都保留），之后继续往这个文件夹里增量复制，
  不会再多出一个新文件夹。设备当时不在线时会等到下次接入复制时改名。
- 「用本机磁盘填充匹配值…」可以直接从当前磁盘里取值，不用手抄序列号。
- 列表里点一行可载入修改，再点「保存修改」；「删除选中」删除。

### 6）设置

| 项目 | 说明 |
|---|---|
| U 盘复制目标根目录 | 手输或「选择…」；目录不存在会问你是否创建 |
| 开机自动启动 | 在「开始菜单 → 启动」里创建 / 删除快捷方式（不写注册表） |
| 启用定时切换 | 定时计划总开关 |
| 记录设备移除事件 | 关闭后只记接入 |
| 最小化窗口时收进托盘并上锁 | 默认开启 |
| 关闭面板后继续在后台监控与复制 | 默认开启（推荐）；关掉后关面板即停引擎，重启后必须先解锁 |
| 复制前检查目标文件是否还在 | 默认开启：增量复制时发现目标文件被误删，就按右边的选择处理 |
| （右边下拉）目标文件不存在时 | **重新复制**（默认，能自动补回被误删的文件）或 **不复制** |
| 日志保留天数 | 7 / 14（默认）/ 30 天 |
| 保存设置 | 保存并立即生效 |
| 修改密码… | 需当前密码；恢复码不变 |
| 重新生成恢复码… | 需当前密码 + 二次确认，旧码立即失效 |
| 立即上锁 | 面板消失，重新打开需要密码 |
| 数据位置 | 程序目录 / 数据目录 / 数据库 / 密钥库 / 日志目录 / 自启快捷方式状态 |

### 7）日志

- 左侧是日志文件列表（日期 + 大小），点一行右侧就显示内容（默认末尾 300 行）。
- 打开或刷新时会**自动停在最底部**（最新的一行），不用每次自己往下拖；
  长行会自动换行，字号也比以前大一点。
- **会实时自动更新**：日志页开着的时候每秒检查一次，有新日志就自动追加显示（不用点刷新），
  而且仍然停在最底部。
- 日志列表可以右键：打开这个日志文件 / 复制文件路径 / 复制日志内容 / 打开日志文件夹。
- 顶部提示当前保留策略与今天的日志路径。
- 按钮：刷新 / 打开日志文件夹 / 清除 7 天前的日志 / 清除全部日志。
- 行格式：`2026-09-18 19:04:23.123 [INFO ] 设备接入：…`，级别有 DEBUG / INFO / WARN / ERROR。

## 四、托盘与上锁

- 托盘图标提示名只有一个：`SecureVault`。
- **左键单击**：打开面板；如果面板已上锁，会先要求输密码。
- **右键**：只有「退出」一项。

下面这些动作都会**立即上锁**（面板消失、再打开要重新输密码）：

1. 点窗口右上角的 ×（收进托盘 + 上锁）；
2. 按 `Esc`；
3. 设置页点「立即上锁」；
4. 最小化窗口（需要设置里「最小化窗口时收进托盘并上锁」保持勾选）。

默认设置下，上锁**不影响后台监控与复制**——插上盘照样自动复制。
想彻底停止后台运行，就到托盘右键「退出」（需要输入密码）。

「退出」的行为：没设过密码时直接退出；设过密码时必须输入密码才退出。

**忘记密码**：在解锁窗口点「忘记密码」，先输入恢复码。程序会**先校验**——
先查格式（12 位、只含规定字符、分段为 XXXX-XXXX-XXXX），再真的拿它去解一次密钥库；
只有通过了才会让你设置新密码，重置成功后会生成新的恢复码（旧恢复码立即失效）。

**密码什么时候会"计入错误次数"**：只有**开软件时在解锁窗口输密码**才计数
（连续 5 次错会锁定 60 秒）。在设置里改密码、重新生成恢复码、确认退出，
或者清除记录 / 清除日志时的密码确认，**输错都不计数**，不会因此被锁。

**危险操作**：清除监控记录、清除日志之前都会先弹一个老式密码框要求确认。

## 五、常见问题排查

| 现象 | 原因 / 处理 |
|---|---|
| 双击没反应 | 先看托盘（可能在「^」里）。程序目录不可写时会弹错误框并退出（退出码 3） |
| 插上 U 盘没有反应 | ① 模式是不是「关闭」？② 「状态 → 当前设备」点刷新看有没有识别到；③ 看日志页有没有「设备接入」 |
| 记录里有「未设置复制目标目录」 | 到设置页填复制目标并保存 |
| 记录里是「已排除」 | 命中了排除规则，到排除名单页检查规则（备注里会写是哪条） |
| 有的文件没复制 | 检查文件名 / 扩展名名单；隐藏或系统文件默认也会被跳过（如果开了「跳过隐藏」） |
| 复制中断，提示空间不足 | 目标盘满了，程序会安全停止，已复制的文件保持有效；清出空间后再插一次会继续增量复制 |
| 忘了密码 | 解锁界面「忘记密码 / 用恢复码重置」；恢复码也丢了就没办法了 |
| 托盘图标不见 | Explorer 重启后程序会自动加回；若是无桌面会话（服务 / 计划任务）则本来就加不上 |
| 想完全停掉 | 托盘右键「退出」 |
